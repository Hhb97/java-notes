# 偏导数与梯度：多个旋钮的世界

> [!ABSTRACT] 一句话版本
> - 真实的函数有**很多个输入**（很多旋钮）：`f(x, y)`、`L(w, b)`，甚至几亿个参数的 `L(θ)`。
> - **偏导数** `∂f/∂x`：**固定其他旋钮，只拧 x**，函数变化得多快。
> - **梯度** `∇f`：把所有偏导数按顺序排成向量。它**指向上坡最陡的方向**，长度是坡度，并且**垂直于等高线**。
> - 沿 `−∇f` 走一小步，函数（通常）会下降，这就是梯度下降；它不保证直指谷底，只管“脚下最陡”。
> - **雅可比矩阵**是“多个输出对多个输入”的偏导表，**Hessian** 是二阶偏导表（认识即可）。

## 一、多变量函数：曲面与等高线

先想一个登山的画面：山的**海拔**取决于你站的位置，也就是东西、南北两个坐标 `(x, y)`。海拔就是一个二元函数 `f(x, y)`，把每个位置映射成一个高度。

AI 里到处是这样的函数：

| 函数 | 输入（旋钮） | 输出 |
| --- | --- | --- |
| 房价 `f(面积, 房龄)` | 2 个 | 价格 |
| 线性回归损失 `L(w, b)` | 2 个 | 总误差 |
| 神经网络损失 `L(θ)` | 几百万到几千亿个 | 一个数 |

二元函数的图像是一张**曲面**；把曲面上相同高度的点连起来投影到平面，就得到**等高线图**（地图上画的那种）。以后我们用这个函数当主角：

```text
f(x, y) = x² + 4y²        一个“碗”，最低点在 (0, 0)，f = 0
f(2, 0.5) = 4 + 1 = 5     f(1, 1) = 1 + 4 = 5     （这两点在同一条 f = 5 的等高线上）
f(0, 1) = 4               f(3, 0) = 9
```

因为 y 的系数是 4，y 方向“弯得更陡”，所以等高线是**扁扁的椭圆**。

### 2. 定义与记号

```text
∂f/∂x = lim (h→0) [ f(x + h, y) − f(x, y) ] / h          （只让 x 变，y 当常数）
∂f/∂y = lim (h→0) [ f(x, y + h) − f(x, y) ] / h          （只让 y 变，x 当常数）
```

`∂`（圆体的 d，念“偏”）专门用来区分偏导与普通导数 `d`。`∂f/∂x` 念作“f 对 x 的偏导”。**求法一句话：对谁求偏导，就把谁当变量，其他字母全当常数，然后按一元求导。**

### 手算例子 1：`f(x, y) = x² + 3xy + y²`

```text
∂f/∂x：y 当常数。x² → 2x；3xy → 3y（3y 是 x 的系数）；y² 是常数 → 0     ∂f/∂x = 2x + 3y
∂f/∂y：x 当常数。x² → 0；3xy → 3x；y² → 2y                              ∂f/∂y = 3x + 2y
```

在点 `(1, 2)`：`f = 1 + 6 + 4 = 11`，`∂f/∂x = 2 + 6 = 8`，`∂f/∂y = 3 + 4 = 7`。

**用数字核对**：只动 x，让 `x` 从 1 变成 1.01：`f(1.01, 2) = 1.0201 + 6.06 + 4 = 11.0801`，变化 `0.0801`，除以 `0.01` 得 **8.01** ≈ 8 ✓。只动 y，`f(1, 2.01) = 11.0701`，得 **7.01** ≈ 7 ✓。

> [!WARNING] 常见误区：偏导里别忘了“另一个变量是常数”
> 求 `∂/∂x` 时，`3xy` 里的 `y` 不会“消失”，它作为系数留下（得 `3y`）；而完全不含 x 的项（如 `y²`）才变成 0。把 `3xy` 当成 `3x²` 或 `3y` 是最常见的错。

### 手算例子 2：`f = x² + 4y²` 在 `(2, 0.5)`

`∂f/∂x = 2x = 4`，`∂f/∂y = 8y = 4`。意思是：x 方向和 y 方向，此刻“坡度”都是 4。

## 三、梯度：把偏导数打包成向量

把所有偏导数**按旋钮的顺序**排成一个向量，就是梯度，记作 `∇f`（nabla，念“nabla f”或“f 的梯度”）：

```text
∇f = ( ∂f/∂x , ∂f/∂y )        对 f = x² + 4y²：  ∇f = ( 2x , 8y )
在 (2, 0.5)：∇f = (4, 4)       长度 ‖∇f‖ = √(16 + 16) = 4√2 ≈ 5.66
```

梯度有三条性质，值得牢记：

1. **方向**：指向函数值**上升最快**的方向（最陡的上坡）；
2. **长度**：`‖∇f‖` 就是那个方向上的坡度，越长越陡；
3. **垂直于等高线**：沿着等高线走，高度不变；上坡最快的方向必然与“高度不变的方向”成直角。

所以 **负梯度 `−∇f` 是下山最快的方向**，梯度下降就走这个方向。再看一个重要细节：在 `(2, 0.5)`，`−∇f = (−4, −4)`，而谷底在 `(0, 0)`，方向是 `(−2, −0.5)`，**两者不一致**。梯度只告诉你“脚下最陡”，不保证“正对终点”。在山谷细长（各方向弯曲程度差异大）时，这会造成**之字形**。

## 四、方向导数：为什么梯度方向最陡

如果你不沿 x 或 y 轴走，而是朝**任意单位向量** `u`（长度为 1 的方向）走，函数的变化率叫**方向导数**：

```text
D_u f = ∇f · u = ‖∇f‖ · ‖u‖ · cos θ = ‖∇f‖ · cos θ          （θ 是 ∇f 与 u 的夹角，‖u‖ = 1）
```

`∇f · u` 是**点积**（对应位置相乘再相加，向量一页详谈）。`cos θ` 最大是 1，所以变化率**最大值是 ‖∇f‖，当且仅当 u 与 ∇f 同向（θ = 0）**；`θ = 90°` 时 `cos θ = 0`，变化率为 0，即沿等高线走；`θ = 180°` 时是 `−‖∇f‖`，下降最快。这就是“梯度方向最陡”的全部道理。

### 手算例子 3：在 `(2, 0.5)`，`∇f = (4, 4)`

| 走的方向 `u` | `∇f · u` | 含义 |
| --- | --- | --- |
| `(1, 0)`（向 +x） | `4×1 + 4×0 = 4` | 与偏导 `∂f/∂x` 相同 |
| `(0, 1)`（向 +y） | `4` | 与 `∂f/∂y` 相同 |
| `(1, 1)/√2`（沿梯度） | `8/√2 ≈ 5.657` | **最大**，等于 ‖∇f‖ |
| `(1, −1)/√2`（沿等高线） | `0` | 高度不变 |
| `(−1, −1)/√2`（负梯度） | `−5.657` | **下降最快** |

用数值核对沿梯度方向：`h = 10⁻⁶` 时 `[f(2 + h/√2, 0.5 + h/√2) − f(2, 0.5)]/h ≈ 5.656857`，与 `4√2 = 5.656854` 一致。

## 五、沿负梯度走一步

更新规则（和上一章学的一元情形完全一样，只是现在是向量）：

```text
(x, y) ← (x, y) − η · ∇f
```

`η`（eta，学习率）是步长。取 `f = x² + 4y²`，从 `(2, 0.5)` 出发，`η = 0.1`：

```text
第 1 步：∇f = (4, 4)       (x, y) = (2 − 0.4, 0.5 − 0.4)   = (1.6, 0.1)    f：5 → 2.6
第 2 步：∇f = (3.2, 0.8)   (x, y) = (1.6 − 0.32, 0.1 − 0.08) = (1.28, 0.02) f：2.6 → 1.64
```

每一步 f 都在下降，且 y 很快被压到接近 0（因为 y 方向坡度更陡）。若把学习率换成 `η = 0.2`：`(2, 0.5) → (1.2, −0.3) → (0.72, 0.18) → (0.432, −0.108)`，**y 在 0 附近来回跨**，这就是之字形；`f` 为 `5 → 1.8 → 0.648 → 0.233`，仍在下降，但 y 在“冲过头”。`η` 太大时，这种过冲会导致发散（见[极值与优化](#/math/optimization)）。

## 六、损失函数对 w、b 的偏导（手算）

线性回归的模型是 `ŷ = w·x + b`。给定 `n` 个数据点，**均方误差**为

```text
L(w, b) = (1/n) · Σᵢ (w·xᵢ + b − yᵢ)²
```

读作“每个点的误差平方，加起来，取平均”。把 `eᵢ = w·xᵢ + b − yᵢ` 记作第 i 个点的误差，用链式法则（下一页专讲）的最简形式：`∂(eᵢ²)/∂w = 2eᵢ·xᵢ`（因为 `eᵢ` 对 `w` 的偏导是 `xᵢ`），`∂(eᵢ²)/∂b = 2eᵢ·1`：

```text
∂L/∂w = (2/n) · Σᵢ eᵢ · xᵢ
∂L/∂b = (2/n) · Σᵢ eᵢ
```

### 手算例子 4：3 个数据点

数据 `(x, y) = (1, 2), (2, 3), (3, 5)`，初值 `w = 0, b = 0`：

```text
eᵢ = w·xᵢ + b − yᵢ = 0 − yᵢ = (−2, −3, −5)
L = (4 + 9 + 25)/3 ≈ 12.667
∂L/∂w = (2/3)·[(−2)(1) + (−3)(2) + (−5)(3)] = (2/3)·(−23) ≈ −15.333
∂L/∂b = (2/3)·[(−2) + (−3) + (−5)]          = (2/3)·(−10) ≈ −6.667
```

两个偏导都是负的：w 和 b 调大都会让损失变小。取 `η = 0.05`：

```text
w ← 0 − 0.05 × (−15.333) = 0.7667       b ← 0 − 0.05 × (−6.667) = 0.3333
新误差 eᵢ = (−0.9, −1.1333, −2.3667)      L = (0.81 + 1.2844 + 5.6011)/3 ≈ 2.565
```

一步之后损失从 12.667 降到 2.565。这个问题的最优解是 `w = 1.5, b = 0.3333`（最小二乘，投影一页会推导），可见 b 已经很接近了。

## 七、向量值函数、雅可比矩阵与 Hessian（认识级别）

### 1. 雅可比矩阵

当**输出也是多个**时，例如 `F(x, y) = (x²y, x + y²)`（2 个输入，2 个输出），把每个输出对每个输入的偏导排成一张表，叫**雅可比矩阵** `J`（第 i 行第 j 列是 `∂Fᵢ/∂xⱼ`）：

```text
J = | ∂F₁/∂x  ∂F₁/∂y |  =  | 2xy   x² |            在 (1, 2)：J = | 4  1 |
    | ∂F₂/∂x  ∂F₂/∂y |     | 1     2y |                           | 1  4 |
```

它描述了“在这一点附近，F 近似是一个线性变换 J”。最重要的特例：一层网络 `z = W·x + b`，每个输出 `zᵢ = Σⱼ Wᵢⱼ xⱼ + bᵢ`，对 `xⱼ` 的偏导正是 `Wᵢⱼ`，所以**这一层的雅可比矩阵就是 W**。反向传播就是在一连串雅可比矩阵之间“接力”。

### 2. 二阶偏导与 Hessian

对一阶偏导再求偏导，得到二阶偏导，排成的表叫 **Hessian 矩阵** `H`（读“黑塞”）：

```text
f = x² + 3xy + y²：  fₓₓ = 2   fₓᵧ = 3   fᵧₓ = 3   fᵧᵧ = 2      H = | 2  3 |
                                                                     | 3  2 |
f = x² + 4y²：       H = | 2  0 |      两个方向都向上弯（对角线都是正数）→ 碗；y 方向弯得更陡（8 > 2）
                         | 0  8 |
```

`H` 刻画“各方向弯曲的程度”：`x² + 4y²` 是椭圆形的碗；`x² + 3xy + y²` 的 H 特征值为 5 和 −1（一正一负）是**鞍点**形状，不是碗。特征值的含义见[特征值与特征向量](#/math/eigen)，二阶信息的用法见[泰勒展开与二阶信息](#/math/taylor)。

## 八、动手：用 Python 验证

```python
import numpy as np, torch

g = lambda x, y: x**2 + 4*y**2
x0, y0, h = 2.0, 0.5, 1e-6
gx = (g(x0 + h, y0) - g(x0 - h, y0)) / (2*h)       # 对 x 的偏导（中心差分）
gy = (g(x0, y0 + h) - g(x0, y0 - h)) / (2*h)
print(round(gx, 4), round(gy, 4))                  # 4.0 4.0

# 线性回归损失对 w、b 的偏导（含自动微分核对）
X = torch.tensor([1., 2., 3.]); Y = torch.tensor([2., 3., 5.])
w = torch.tensor(0., requires_grad=True); b = torch.tensor(0., requires_grad=True)
L = ((w*X + b - Y)**2).mean()
L.backward()
print(f"{L.item():.3f} {w.grad.item():.3f} {b.grad.item():.3f}")   # 12.667 -15.333 -6.667
```

输出与手算一致（自动微分用 float32，所以只保留三位小数）。

## 自测：你真的懂了吗？

> [!QUESTION] 求 `f(x, y) = x²y + y³` 的两个偏导，并求在 `(1, 2)` 的梯度。
> `∂f/∂x = 2xy`，`∂f/∂y = x² + 3y²`。在 `(1, 2)`：`∂f/∂x = 4`，`∂f/∂y = 1 + 12 = 13`，所以 `∇f = (4, 13)`。

> [!QUESTION] 在某点 `∇f = (3, 4)`，沿单位向量 `u = (0.6, 0.8)` 的方向导数是多少？最大的方向导数又是多少？
> `∇f · u = 3×0.6 + 4×0.8 = 5`。`‖∇f‖ = √(9 + 16) = 5`，二者相等，因为 `u` 恰好与 ∇f 同向（`u = ∇f/5`）。最大变化率就是 5。

> [!QUESTION] 为什么梯度要垂直于等高线？
> 沿等高线走，函数值不变，方向导数 `∇f · u = 0`，所以 ∇f 与等高线的切线方向垂直。同理上坡最快的方向与“高度不变的方向”必成直角。

> [!QUESTION] 对数据 `(1, 2), (2, 3), (3, 5)`，取 `w = 1, b = 0`，算 `∂L/∂w` 和 `∂L/∂b`。
> `eᵢ = xᵢ − yᵢ = (−1, −1, −2)`。`∂L/∂w = (2/3)(−1×1 − 1×2 − 2×3) = (2/3)(−9) = −6`；`∂L/∂b = (2/3)(−1 − 1 − 2) = −8/3 ≈ −2.667`。

> [!QUESTION] 沿负梯度走一步为什么不一定直接到谷底？
> 梯度只反映当前点附近“最陡”的方向。如果各方向的弯曲程度差别很大（椭圆形山谷），最陡方向并不指向最低点；而且步长太大会冲过头，形成之字形或发散。
