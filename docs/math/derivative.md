# 导数：变化率、切线与求导法则

> [!ABSTRACT] 一句话版本
> - **导数** = 函数在某一点的**瞬时变化率**，几何上是**切线的斜率**。你可以把它想成汽车仪表盘上的“速度表”。
> - 定义是一个极限：`f′(x) = lim (f(x+h) − f(x))/h`，即“割线斜率在 `h → 0` 时的归宿”。
> - 记住一张公式表和几条法则，就能求出绝大多数函数的导数；AI 里最常见的是 sigmoid、tanh、ReLU、`ln x`、`eˣ`、平方损失。
> - 导数的**符号**告诉你函数往哪走：正则上升、负则下降、零则可能到了谷底或山顶。
> - 解析导数（手推）、数值导数（用小 h 算）、自动微分（框架帮你算）三者互相印证，其中**数值导数是检查梯度代码的利器**。

## 一、从速度到瞬时变化率

你开车，里程表读数随时间增加。**平均速度 = 位置变化 ÷ 时间变化**，比如 2 小时走了 120 公里，平均 60 公里/小时。可平均速度掩盖了“某一瞬间到底多快”：中间可能堵车，也可能飙到 100。

“**某一瞬间的速度**”是怎么算的？取一个**很短很短的时间段**，算这段的平均速度，让时间段越缩越短：1 秒 → 0.1 秒 → 0.01 秒……平均速度会稳定在某个值，那就是瞬时速度。这个“缩到无限短后的归宿”就是**极限**（上一页刚讲过），瞬时速度就是位置对时间的**导数**。

一般地，函数 `y = f(x)` 在点 `x` 的导数，就是 `y` 随 `x` 变化的瞬时快慢。

## 二、割线逼近切线

取曲线 `f(x) = x²`，固定点 `(1, 1)`，再取邻居点 `(1+h, (1+h)²)`。连接两点的直线叫**割线**，它的斜率是“纵向变化 ÷ 横向变化”：

```text
割线斜率 = [ f(1+h) − f(1) ] ÷ h = [ (1+h)² − 1 ] ÷ h = (2h + h²) ÷ h = 2 + h
```

h 越小，邻居点越靠近，割线越贴近曲线在 `(1,1)` 处的**切线**：

## 三、导数的定义与手算

```text
f′(x) = lim (h→0) [ f(x + h) − f(x) ] / h
```

读作“f 撇 x 等于 h 趋于 0 时，（f(x+h) − f(x)）除以 h 的极限”。`f′`（念“f 撇”）和 `df/dx`（念“d f d x”）是同一个东西的两种写法，后者强调“`f` 随 `x` 的变化率”。

### 手算例子 1：按定义求 `x²` 的导数

```text
f(x+h) − f(x) = (x+h)² − x² = 2xh + h²
[ f(x+h) − f(x) ] / h = (2xh + h²)/h = 2x + h        （h ≠ 0，可以约掉 h）
h → 0：              f′(x) = 2x
```

于是 `x = 1` 时导数 2，`x = 3` 时导数 6（离原点越远，曲线越陡）。数值验证 `x = 3`：`h=1` 得 7，`h=0.1` 得 6.1，`h=0.01` 得 6.01，的确奔向 6。

> [!WARNING] 常见误区：导数是一个数，还是一个函数？
> 在**某一点**，导数是一个数（斜率）；把每个点的导数都写出来，得到**导函数** `f′(x)`。例如 `f′(x) = 2x` 是导函数，`f′(3) = 6` 才是“在 3 处的导数”。

## 四、求导公式表与法则

### 1. 常用公式

| 函数 `f(x)` | 导数 `f′(x)` | 说明 |
| --- | --- | --- |
| 常数 `c` | `0` | 不变化，斜率为 0 |
| `xⁿ` | `n·xⁿ⁻¹` | `x³ → 3x²`；`√x = x^0.5 → 0.5·x^(−0.5)`；`1/x → −1/x²` |
| `eˣ` | `eˣ` | 导数是它自己（这是 e 的招牌性质） |
| `aˣ` | `aˣ·ln a` | `2ˣ → 2ˣ·0.693` |
| `ln x` | `1/x` | 仅 `x > 0` |

### 2. 四则法则

| 法则 | 公式 | 例子 |
| --- | --- | --- |
| 和差 | `(f ± g)′ = f′ ± g′` | `(x² + 3x)′ = 2x + 3` |
| 常数倍 | `(c·f)′ = c·f′` | `(5x²)′ = 10x` |
| 乘法 | `(f·g)′ = f′g + f g′` | `(x·eˣ)′ = eˣ + x·eˣ = eˣ(1 + x)` |
| 除法 | `(f/g)′ = (f′g − f g′) / g²` | `(x/(1+x))′ = [1·(1+x) − x·1]/(1+x)² = 1/(1+x)²` |
| 链式（预告） | `(f(g(x)))′ = f′(g(x))·g′(x)` | 一环扣一环，见[链式法则与反向传播](#/math/chain-backprop) |

**手算例子 2**：`f(x) = x·eˣ` 在 `x = 0` 的导数。用乘法法则：`f′(x) = eˣ(1 + x)`，代入 0 得 `e⁰ × 1 = 1`。再验证 `(x/(1+x))′` 在 `x = 1`：`1/(1+1)² = 0.25`，用 `h = 10⁻⁶` 算数值导数得 `0.24999987…`，吻合。

> [!NOTE] 这些公式不用背成“考点”
> 你要建立的是**直觉**：`xⁿ` 的次数越高，曲线越陡；`eˣ` 越长越快，斜率正好等于自己；`ln x` 越往右越平。需要时查表即可。

## 五、AI 里最常见函数的导数

### 1. sigmoid：`σ′ = σ(1 − σ)`（完整推导）

`σ(x) = 1/(1 + e⁻ˣ)`。用除法法则：分子 `1`（导数 0），分母 `g = 1 + e⁻ˣ`，而 `(e⁻ˣ)′ = −e⁻ˣ`（负号来自“里层 `−x` 的导数是 −1”，链式法则下一章细讲，这里当公式用），所以 `g′ = −e⁻ˣ`：

```text
σ′(x) = (0·g − 1·g′) / g²  =  e⁻ˣ / (1 + e⁻ˣ)²
```

把它拆成两个因子相乘：

```text
σ′(x) = [ 1/(1 + e⁻ˣ) ] · [ e⁻ˣ/(1 + e⁻ˣ) ]  =  σ(x) · [ 1 − σ(x) ]
```

最后一步因为 `1 − σ = (1 + e⁻ˣ − 1)/(1 + e⁻ˣ) = e⁻ˣ/(1 + e⁻ˣ)`。

**数值**（可心算核对）：

| x | σ(x) | σ′(x) = σ(1−σ) |
| --- | --- | --- |
| 0 | 0.5 | 0.5 × 0.5 = **0.25**（最大） |
| 2 | 0.8808 | 0.8808 × 0.1192 ≈ 0.105 |
| 5 | 0.9933 | 0.9933 × 0.0067 ≈ 0.0066 |
| −5 | 0.0067 | 0.0067 × 0.9933 ≈ 0.0066 |

| 函数 | 导数 | 备注 |
| --- | --- | --- |
| tanh `x` | `1 − tanh²(x)` | `tanh(1) = 0.7616`，导数 `1 − 0.58 = 0.42`；在 0 处导数为 1（最大） |

| 平方损失 `L = (ŷ − y)²` | `dL/dŷ = 2(ŷ − y)` | `ŷ = 0.8, y = 1`：`2 × (−0.2) = −0.4`，负号表示“把 ŷ 调大会更好” |

- `f′(x) > 0`：函数在**上升**（切线向右上）；
- `f′(x) < 0`：函数在**下降**；
- `f′(x) = 0`：切线水平，可能是**谷底、山顶或平台**（这些点叫驻点）。

**手算例子 3**：`f(x) = x² − 4x + 3`，导函数 `f′(x) = 2x − 4`。令 `f′ = 0` 得 `x = 2`；`x < 2` 时 `f′ < 0`（降），`x > 2` 时 `f′ > 0`（升），所以 `x = 2` 是**最小值点**，`f(2) = 4 − 8 + 3 = −1`。

**二阶导数**（导数的导数，预告）：`f″(x) = 2 > 0`，表示曲线“向上弯”，像碗，这正是谷底；`f″ < 0` 则像帽子，是山顶。二阶导数的完整故事在[极值与优化](#/math/optimization)和[泰勒展开](#/math/taylor)里。

### 可导与不可导

- 在 `x = a` **可导**：切线唯一、左右斜率相同。
- **尖点**不可导：`|x|` 在 0 处，左边斜率 −1、右边斜率 +1，左右不等，导数不存在；ReLU 也一样（左 0、右 1）。
- **可导必连续，连续不一定可导**：`|x|` 处处连续，却在 0 点有折角；阶跃函数不连续，更谈不上导数。

## 七、三种求导：解析、数值、自动微分

| 方式 | 做法 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **解析导数** | 用公式手推 | 精确、最快 | 函数一复杂就容易推错 |
| **数值导数** | `(f(x+h) − f(x))/h`，h 取很小 | 实现简单，**检查别的方法** | 有误差；h 太大截断误差大，太小舍入误差大；参数多时极慢 |
| **自动微分** | 框架记录运算，按链式法则自动算 | 精确，参数再多也只需一次反向 | 需要框架（PyTorch / JAX） |

对 sigmoid 在 `x = 0.5` 处检验：解析值 `σ(1−σ) = 0.6225 × 0.3775 = 0.2350`。用不同 `h` 做数值导数，看误差：

| h | 前向差分误差 | 中心差分误差 |
| --- | --- | --- |
| `10⁻¹` | 3.0e-03 | 1.6e-04 |
| `10⁻³` | 2.9e-05 | 1.6e-08 |
| `10⁻⁵` | 2.9e-07 | 4.0e-13 |
| `10⁻⁸` | 4.3e-09 | 4.3e-09 |
| `10⁻¹²` | 8.1e-05 | 2.5e-05 |

规律：h 缩小，误差先降后升（太小了，计算机的舍入误差反而变大）；**中心差分** `(f(x+h) − f(x−h))/(2h)` 比前向差分精度高得多，`h ≈ 10⁻⁵` 是个好选择。

**梯度检验**（gradient check）：自己手写反向传播时，用数值导数对照，**相对误差** `|g_数值 − g_解析| / max(|g_数值|, |g_解析|)` 小于 `10⁻⁶` 左右通常说明没写错。这是调试神经网络最实用的招数。

## 八、动手：Python 验证

```python
import math, torch

sigmoid = lambda x: 1 / (1 + math.exp(-x))
x = 0.5
ana = sigmoid(x) * (1 - sigmoid(x))              # 解析：σ(1−σ)
h = 1e-5
num = (sigmoid(x + h) - sigmoid(x - h)) / (2 * h)  # 数值：中心差分
print(ana, num)                                   # 0.2350037122015945 0.23500371220119828

xt = torch.tensor(0.5, requires_grad=True)        # 自动微分
torch.sigmoid(xt).backward()
print(xt.grad)                                    # tensor(0.2350)

z = torch.tensor(0.0, requires_grad=True)         # ReLU 在 0 处的约定
torch.relu(z).backward()
print(z.grad)                                     # tensor(0.)
```

## 九、和 AI 的对照表

| 导数的概念 | 在 AI 里的样子 |
| --- | --- |
| 导数 = 斜率 | 参数调大一点，损失怎么变 |
| 导数符号 | 决定更新方向：`w ← w − η·f′(w)` |
| `σ′ = σ(1−σ) ≤ 0.25` | sigmoid 层梯度逐层变小（梯度消失） |
| ReLU 导数是 0 或 1 | 正的通路“原样放行”，负的通路“关闭” |
| `d(−ln p)/dp = −1/p` | 交叉熵对预测概率的敏感度 |
| 数值导数 / 自动微分 | 梯度检验 / PyTorch `backward()` |

## 自测：你真的懂了吗？

> [!QUESTION] 按定义求 `f(x) = 3x²` 的导数，并求 `f′(2)`。
> `[3(x+h)² − 3x²]/h = (6xh + 3h²)/h = 6x + 3h → 6x`。所以 `f′(x) = 6x`，`f′(2) = 12`。

> [!QUESTION] 求 `f(x) = x²·eˣ` 在 `x = 1` 处的导数。
> 乘法法则：`f′ = 2x·eˣ + x²·eˣ = eˣ(2x + x²)`，代入 1 得 `3e ≈ 8.155`。

> [!QUESTION] 已知 `σ(2) ≈ 0.8808`，不查表求 `σ′(2)`，并说明 `σ′` 的最大值。
> `σ′(2) = σ(2)(1 − σ(2)) = 0.8808 × 0.1192 ≈ 0.105`。`σ(1−σ)` 在 `σ = 0.5`（即 `x = 0`）时最大，为 `0.25`。

> [!QUESTION] 找出 `f(x) = x² − 6x + 5` 的最小值点，并写出判断依据。
> `f′ = 2x − 6 = 0 → x = 3`，`f(3) = −4`。`x < 3` 时导数为负（降），`x > 3` 时为正（升），所以是最小点。（也可用 `f″ = 2 > 0`：向上弯，驻点就是谷底。）

> [!QUESTION] 为什么说 ReLU 在 0 处不可导，实际训练还能照常用？
> 0 处左斜率 0、右斜率 1，左右不等，所以不可导。但输入**恰好等于 0** 的概率极小，框架约定该点导数取 0（或 1）即可，对训练几乎没有影响。
