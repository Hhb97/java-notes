# 函数、极限与连续：用“逼近”理解变化

> [!ABSTRACT] 一句话版本
> - **极限**：自变量越来越靠近某个值时，函数值**奔向哪里**。关键词是“逼近”，不要求到达，也不要求那一点有定义。
> - **连续**：图像能**一笔画下来**，没有洞、断崖、飞走。形式上是“极限 = 函数值”。
> - 激活函数要**连续**（最好还可导）：阶跃函数处处斜率为 0，梯度传不回去，所以神经网络用 sigmoid、ReLU 而不用阶跃。
> - 训练“收敛”就是参数序列有极限；`exp(1000)` 溢出可以用“**先减最大值**”的 log-sum-exp 技巧绕开。

## 一、极限直觉：逼近而不到达

先看一个“有点怪”的函数：

```text
f(x) = (x² − 1) / (x − 1)
```

问：`x = 1` 时 `f` 是多少？代进去得 `0/0`，**没有定义**。但如果我们去 `x = 1` 的**附近**看呢？

| x（从左边靠近） | f(x) | x（从右边靠近） | f(x) |
| --- | --- | --- | --- |
| 0.5 | 1.5 | 1.5 | 2.5 |
| 0.9 | 1.9 | 1.1 | 2.1 |
| 0.99 | 1.99 | 1.01 | 2.01 |
| 0.999 | 1.999 | 1.001 | 2.001 |

无论从哪边靠近，函数值都在**奔向 2**。你可以把它想成走向一扇门：每一步都走剩下距离的一半，永远“没到”，但你**很清楚终点在哪**。

为什么是 2？把分子分解：`x² − 1 = (x−1)(x+1)`，当 `x ≠ 1` 时约掉 `(x−1)`，得 `f(x) = x + 1`。所以 `x` 靠近 1 时，`x + 1` 靠近 2。注意“`x ≠ 1`”：极限**不看那一点本身**。

**定义**：当 x 趋近 a 时，若 `f(x)` 趋近某个数 `L`，就写成

```text
lim f(x) = L        （x → a，念“x 趋于 a 时，f(x) 的极限是 L”）
```

`lim` 是 limit（极限）的缩写，`→` 念“趋于”。上面的结论写成：`lim (x→1) (x²−1)/(x−1) = 2`。

### 手算例子 1：数列 `(1 + 1/n)ⁿ`

`n` 是正整数，`n → ∞`（念“n 趋于无穷大”，表示 n 无限变大）。逐个算：

| n | 1 | 2 | 5 | 10 | 100 | 1000 | 10000 | 1000000 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `(1+1/n)ⁿ` | 2 | 2.25 | 2.4883 | 2.5937 | 2.7048 | 2.7169 | 2.7181 | 2.71828 |

比如 `n = 2`：`(1 + 1/2)² = 1.5² = 2.25`。数值一路涨、越涨越慢，奔向 **`2.71828…`**，这个数就是 **e**：`lim (n→∞) (1 + 1/n)ⁿ = e`。

> [!WARNING] 常见误区：极限不等于“函数值”
> “极限是 2” 不代表 “`f(1) = 2`”。极限描述的是**附近的趋势**；`f(1)` 可以没定义，甚至可以被人为设成别的数。把两者分清，是理解“连续”的前提。

## 二、无穷大、无穷小与运算法则

- **无穷小**：趋近 0 的量，如 `x → ∞` 时的 `1/x`：`x = 10, 100, 1000` 时 `1/x = 0.1, 0.01, 0.001`。
- **无穷大**：绝对值无限变大的量，如 `x → 0⁺` 时的 `1/x`：`0.1, 0.01, 0.001` 对应 `10, 100, 1000`。此时我们说极限“不存在”（发散到无穷）。

极限有一套**像算术一样的法则**，只要各个极限都存在：

| 法则 | 写法 | 前提 |
| --- | --- | --- |
| 和差 | `lim (f ± g) = lim f ± lim g` | 两个极限都存在 |
| 常数倍 | `lim (c·f) = c·lim f` | |
| 乘积 | `lim (f·g) = lim f · lim g` | |
| 商 | `lim (f/g) = lim f ÷ lim g` | 分母的极限 ≠ 0 |

**手算例子 2**：`lim (x→2) (x² + 3x)/(x + 1)`。分子极限 `4 + 6 = 10`，分母极限 `3 ≠ 0`，结果 `10/3 ≈ 3.33`（这里直接代入就行，因为函数在 2 处连续）。

**手算例子 3**：`lim (x→∞) (3x² + 1)/(x² + 5)`。分子分母同除以 `x²`：

```text
(3 + 1/x²) / (1 + 5/x²)     x → ∞ 时 1/x² → 0     →     (3 + 0)/(1 + 0) = 3
```

“**同除以最高次**，让无穷小冒出来”是处理这类题的标准手法。

## 三、单侧极限、连续与三种间断

### 1. 单侧极限

有时左右两边趋势不同，需要分开说：

- `lim (x→a⁻) f(x)`：**左极限**，只从比 a 小的一侧靠近；
- `lim (x→a⁺) f(x)`：**右极限**，只从比 a 大的一侧靠近。

**极限存在，当且仅当左右极限都存在且相等。** 例如符号函数 `|x|/x`：`x → 0⁻` 时恒为 `−1`，`x → 0⁺` 时恒为 `+1`，左右不等，所以 `x → 0` 时极限不存在。

### 2. 连续的定义

函数 `f` 在点 `a` **连续**，需要同时满足三条：

```text
① f(a) 有定义     ② lim (x→a) f(x) 存在     ③ lim (x→a) f(x) = f(a)
```

通俗说就是：**图像在 a 处没断、没洞、没飞走，铅笔不用抬起来**。三条里破坏哪一条，就得到不同的间断。

- **ReLU 连续**：`x → 0⁻` 时函数值 0，`x → 0⁺` 时也是 0，且 `ReLU(0) = 0`，三条都满足。它在 0 处有个**折角**：左斜率 0、右斜率 1，所以那一点“导数不存在”（下一页详谈），实践中约定取 0 或 1 就行。
- **阶跃不连续**：左极限 0、右极限 1，是跳跃间断。更致命的是它的**导数**：除了 0 点，处处斜率为 0。

训练要靠 `w ← w − η·∂L/∂w`。若激活函数是阶跃，链式法则里会乘上它的导数，结果恒为 0，于是 `∂L/∂w = 0`，参数**永远不动**。这就是“梯度处处为 0 或不存在 → 学不了”。

> [!TIP] sigmoid 可以看成“被磨圆的阶跃”
> sigmoid 在两端像阶跃（趋近 0 和 1），但中间是平滑过渡，处处连续、处处可导，斜率不为 0，所以能把梯度传回去。

## 五、极限在 AI 里的样子

### 1. e 与连续复利

存 100 元，年利率 100%（方便算）。一年结息 1 次，本息 `100 × (1+1)¹ = 200`；每月结 1 次，`100 × (1 + 1/12)¹²`；每天结一次……结得越勤，钱越多，但**有上限**：

| 一年结息 n 次 | 1 | 12 | 365 | 1000000 |
| --- | --- | --- | --- | --- |
| 本息（元） | 200 | 261.30 | 271.46 | 271.83 |

上限就是 `100 × e ≈ 271.83`。这是 `eˣ` 作为“连续增长”的来历，也是它出现在 sigmoid、softmax 里的深层原因。

### 2. 训练“收敛”是什么意思

回到梯度下降的小例子：`L(w) = (w−3)²`，`η = 0.1`，从 `w₀ = 0` 出发，每步 `w ← w − 0.1·2(w−3)`。得到一个**序列** `w₀, w₁, w₂, …`：

| 步数 k | 0 | 1 | 2 | 3 | 5 | 10 | 20 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `wₖ` | 0 | 0.6 | 1.08 | 1.464 | 2.017 | 2.678 | 2.965 |
| 离 3 的距离 | 3 | 2.4 | 1.92 | 1.536 | 0.983 | 0.322 | 0.035 |

每步距离恰好乘以 0.8，所以 `距离 = 3 × 0.8ᵏ`，趋近 0。我们说“**序列 `wₖ` 的极限是 3**”，写成 `lim (k→∞) wₖ = 3`。工程里没人真的跑到无穷，而是约定一个**容忍度 ε**（如 `0.01`）：当 `|wₖ − 3| < ε` 之后不再超出，就算“收敛了”。这里 `3 × 0.8ᵏ < 0.01` 需要 `k ≥ 26`。

### 3. `exp(1000)` 溢出与 log-sum-exp 技巧

softmax 需要算 `eᶻ`。但计算机的浮点数有上限：float64 里 `exp(709) ≈ 8.2×10³⁰⁷` 还行，`exp(710)` 就变成 `inf`（无穷）；float32 在 `exp(89)` 就溢出了。

设三个得分（logits）`z = (1000, 1001, 1002)`，直接算：`e¹⁰⁰⁰ = inf`，`inf/inf = nan`，整个计算坏掉。

**技巧**：softmax 的分子分母同时乘以任意常数 `e⁻ᶜ`，结果不变：

```text
softmax(z)ᵢ = e^(zᵢ) / Σⱼ e^(zⱼ) = e^(zᵢ − c) / Σⱼ e^(zⱼ − c)       取 c = max(z)
```

**手算**：`c = 1002`，`z − c = (−2, −1, 0)`，现在最大指数是 0，**不会溢出**：

```text
e^(−2) ≈ 0.1353      e^(−1) ≈ 0.3679      e^0 = 1        和 ≈ 1.5032
softmax = (0.1353, 0.3679, 1) / 1.5032 ≈ (0.0900, 0.2447, 0.6652)
```

同样地，`log Σ e^(zᵢ)`（log-sum-exp，LSE）写成 `c + log Σ e^(zᵢ − c)`：`1002 + ln 1.5032 ≈ 1002.4076`。交叉熵、似然里的 `log` 都靠它稳定。

### 4. 学习率趋近 0 与大数定律（直觉）

- **学习率衰减**：带噪声的 SGD 步子若始终很大，会在最优点附近一直抖；训练后期把 `η` 逐渐**降向 0**，抖动才会平息，序列才能真正“落”在极限上。
- **大数定律**：随机变量的样本平均，随着样本数 `n → ∞`，会趋近它的期望。抛硬币正面比例就是例子：样本越多越接近 0.5。这是“用小批量估计真实梯度”靠谱的原因（见[积分与期望](#/math/integral)）。

```python
naive = np.exp(z) / np.exp(z).sum()        # 警告：overflow，结果全是 nan
print(naive)                               # [nan nan nan]
e = np.exp(z - z.max())                    # 指数部分 ≤ 0，安全
print(e / e.sum())                         # [0.09003057 0.24472847 0.66524096]
print(z.max() + np.log(e.sum()))           # LSE = 1002.4076059644444

# 3) 大数定律：抛硬币正面比例
rng = np.random.default_rng(0)
for n in [10, 100, 10000, 1000000]:
    print(n, rng.integers(0, 2, n).mean())
# 10 0.4 / 100 0.56 / 10000 0.5033 / 1000000 0.500379
```

## 七、小结表

| 概念 | 一句话 | 在 AI 里 |
| --- | --- | --- |
| 极限 | 逼近的趋势，不看那一点 | 收敛、导数的定义（下页） |
| 单侧极限 | 左右分别看 | ReLU 的折角 |
| 连续 | 极限 = 函数值，一笔画成 | 激活函数需要连续 |
| 间断 | 洞 / 断崖 / 飞走 | 阶跃函数无法训练 |
| `e`、`exp` 溢出 | 连续增长的上限；指数爆炸 | softmax 要减最大值 |
| 序列极限 | `wₖ → w*` | 训练收敛、学习率衰减 |

## 自测：你真的懂了吗？

> [!QUESTION] 求 `lim (x→3) (x²−9)/(x−3)`，并说明为什么不能直接代入。
> 直接代入得 `0/0`。分子分解为 `(x−3)(x+3)`，约去 `(x−3)`（`x ≠ 3`），得 `x + 3`，极限为 **6**。

> [!QUESTION] `f(x)=|x|/x` 在 `x→0` 时有极限吗？
> 没有。左极限是 −1，右极限是 +1，左右不等，所以极限不存在（跳跃间断）。

> [!QUESTION] 为什么阶跃函数不适合做神经网络的激活函数，而 ReLU 可以？
> 阶跃函数不连续，且除了 0 点以外导数处处为 0，链式法则里乘上 0，梯度无法传回，参数不更新。ReLU 连续，在 `x > 0` 时导数为 1，梯度可以通过；0 处的折角用约定值处理即可。

> [!QUESTION] 对 `z = (5, 6, 7)` 手算 softmax，并说明为什么“减去最大值”不改变结果。
> 减最大值 7 得 `(−2, −1, 0)`，与上文相同，结果 `(0.0900, 0.2447, 0.6652)`。分子分母同乘常数 `e⁻ᶜ`，会被约掉，所以 softmax 对“整体平移”不变；平移后指数 ≤ 0，不会溢出。

> [!QUESTION] 序列 `wₖ = 3 × 0.8ᵏ` 的极限是多少？训练里“收敛”通常怎么判断？
> 极限为 0（`0.8ᵏ → 0`）。工程上一般看损失或参数变化是否小于容忍度 ε，并连续多步保持，而不是真的跑到无穷。
