# 泰勒展开与二阶信息：为什么这样走有效

> [!ABSTRACT] 一句话版本
> - **泰勒展开**：在一个点附近，用“值 + 斜率 + 弯曲程度……”拼出一个多项式，来**近似**复杂函数。就像放大地图：近处的弯路看起来是直的，再放大一点能看出一点弯。
> - 多元版本：`f(x+Δ) ≈ f(x) + ∇f·Δ + ½ΔᵀHΔ`，三项依次是**当前值、一阶（梯度）、二阶（Hessian）**。
> - **梯度下降**只用前两项，所以只在**小步长**里可信；**第三项**（曲率）告诉你步子最大能迈多大（`η < 2/L`）。
> - **牛顿法**用上三项，直接跳到抛物线的谷底，收敛极快，但 Hessian 太大算不起；于是有 L-BFGS、K-FAC 等近似。
> - AI 里：GELU 的近似公式、把非线性局部**线性化**、估计误差、理解学习率上限，背后都是它。

> [!NOTE] 先决条件
> 需要知道导数和二阶导（[导数](#/math/derivative)）、梯度（[偏导数与梯度](#/math/gradient)）。速成版在 [微积分 1 第七节](#/aimodel/math-calc1)，只讲了一阶；本页补上**二阶**，并用它解释优化。

## 一、用多项式近似函数：常数 → 切线 → 抛物线

### 1. 问题

计算机只会加减乘除，那 `eˣ`、`sin x` 是怎么算出来的？答案之一：**用多项式去逼近**，多项式只需要加减乘。我们在 `x = 0` 附近一项一项地“凑”：

1. **0 阶（常数）**：先保证在 0 处**值**一样：`f(0)`。像一条水平线；
2. **1 阶（切线）**：再让**斜率**一样：加上 `f′(0)·x`。像一条斜线；
3. **2 阶（抛物线）**：再让**弯曲程度**一样：加上 `½f″(0)·x²`。像一条会拐弯的抛物线；
4. 继续加，每一项都让函数在 0 处多一阶导数对上。

### 2. 公式

在展开点 `a` 附近：

```text
f(x) ≈ f(a) + f′(a)(x−a) + f″(a)/2! · (x−a)² + f‴(a)/3! · (x−a)³ + …
```

符号：`f′, f″, f‴` 是一阶、二阶、三阶导数；`n!` 读“n 的阶乘”，`n! = 1×2×…×n`（`2! = 2`，`3! = 6`，`4! = 24`）；`(x−a)` 是“离展开点多远”。除以 `n!` 是为了让第 n 项的 n 阶导数恰好等于 `f⁽ⁿ⁾(a)`。展开点取 0 时又叫**麦克劳林展开**。

### 3. 手算：eˣ

`eˣ` 的各阶导数都是它自己，在 0 处都等于 1，所以

```text
eˣ ≈ 1 + x + x²/2 + x³/6 + x⁴/24 + …
```

算 `e^0.5`（真值 1.6487）：

| 取到几阶 | 近似值 | 误差 |
| --- | --- | --- |
| 0 阶：1 | 1 | 0.6487 |
| 1 阶：1 + 0.5 | 1.5 | 0.1487 |
| 2 阶：+ 0.5²/2 = 0.125 | 1.625 | 0.0237 |
| 3 阶：+ 0.5³/6 = 0.0208 | 1.6458 | 0.0029 |
| 4 阶：+ 0.5⁴/24 = 0.0026 | 1.6484 | 0.0003 |

每加一项，误差大约缩小一个数量级。把 x 换成离 0 更远的 1：1、2、2.5、2.667、2.708，真值 2.718，仍然在逼近，但慢一些。**离展开点越近、阶数越高，越准。**

> [!WARNING] 泰勒近似是“局部”的
> 离展开点越远，误差越大。用 1 阶近似算 `e²`：`1 + 2 = 3`，真值 7.39，差得很远。这条提醒后面会反复用到：**梯度下降的“线性近似”只在小步长内可信**。

## 二、常见展开（认识即可）

| 函数 | 在 0 附近的展开 | 范围 | 一句话 |
| --- | --- | --- | --- |
| `eˣ` | `1 + x + x²/2! + x³/3! + …` | 所有 x | 系数全是 `1/n!` |
| `sin x` | `x − x³/3! + x⁵/5! − …` | 所有 x | 只有奇数次项；小角度 `sin x ≈ x` |
| `cos x` | `1 − x²/2! + x⁴/4! − …` | 所有 x | 只有偶数次项 |
| `ln(1+x)` | `x − x²/2 + x³/3 − …` | `-1 < x < 1` | 小 x 时 `ln(1+x) ≈ x` |
| `1/(1−x)` | `1 + x + x² + x³ + …` | `-1 < x < 1` | **几何级数**，每项乘 x |

小数验证：

```text
sin 0.5：  0.5 − 0.5³/6 = 0.47917         真值 0.47943（再加一项 x⁵/120 → 0.479427）
ln 1.1：   0.1 − 0.1²/2 + 0.1³/3 = 0.09533   真值 0.09531
1/(1−0.1)：1 + 0.1 + 0.01 + 0.001 = 1.111    真值 1.1111
```

**最常用的“小量近似”**：`eˣ ≈ 1 + x`，`ln(1+x) ≈ x`，`sin x ≈ x`，`(1+x)ⁿ ≈ 1 + nx`（x 很小时）。它们在 AI 里很常见，例如 sigmoid 在 0 附近：`σ(z) ≈ 1/2 + z/4`（因为 `σ(0) = 1/2`，`σ′(0) = 1/4`，就是 [链式法则与反向传播](#/math/chain-backprop) 里“sigmoid 导数最大 0.25”的来历）；z = 0.4 时近似 0.6，真值 0.5987。

> [!TIP] 数值稳定的小技巧
> 当 x 极小（如 `1e-10`）时，`1 + x` 在浮点数里会丢精度，`log(1 + x)` 算不准。NumPy/PyTorch 提供 `log1p(x)`、`expm1(x)`，内部就利用了 `ln(1+x) ≈ x` 之类的展开。

## 三、多元泰勒：梯度和 Hessian 登场

函数有很多个输入时，把“离展开点多远”换成**位移向量 Δ**（`Δ = (Δx, Δy, …)`，读“delta”）：

```text
f(x + Δ) ≈ f(x)  +  ∇f(x) · Δ  +  ½ · Δᵀ H Δ
           ①当前值    ②一阶：梯度·位移    ③二阶：Hessian 的二次型
```

- **① `f(x)`**：现在的高度；
- **② `∇f·Δ`**（点积）：沿位移方向，**坡度乘以走的距离**，即“按斜面走会升降多少”；
- **③ `½ΔᵀHΔ`**：**弯曲带来的修正**。`H` 是 Hessian（二阶偏导矩阵，见 [极值与优化](#/math/optimization)）。`ΔᵀHΔ` 是一个数：先用 H 变换 Δ，再和 Δ 点积。对 `H = diag(λ₁, λ₂)`，它等于 `λ₁Δx² + λ₂Δy²`，所以 **H 正定时第三项总是正的（碗向上翘）**。

### 手算

`f(x, y) = x²y + y³`，在 `(1, 1)` 附近走 `Δ = (0.1, −0.1)`：

```text
f(1,1) = 2
∇f = (2xy, x² + 3y²) = (2, 4)                      → ∇f·Δ = 2×0.1 + 4×(−0.1) = −0.2
H  = | 2y  2x  | = | 2 2 |      HΔ = (0.2−0.2, 0.2−0.6) = (0, −0.4)
     | 2x  6y  |   | 2 6 |      ΔᵀHΔ = 0.1×0 + (−0.1)×(−0.4) = 0.04  → ½ΔᵀHΔ = 0.02

一阶近似： 2 − 0.2        = 1.80      （误差 0.018）
二阶近似： 2 − 0.2 + 0.02 = 1.82      （误差 0.002）
真值 f(1.1, 0.9) = 1.818
```

加上二阶项后误差缩小了约 9 倍。

## 四、为什么梯度下降有效：一阶近似只在小步长内可信

沿负梯度走 `Δ = −η·g`（`g = ∇f`），代入泰勒公式：

```text
f(x − ηg) ≈ f(x)  −  η·‖g‖²  +  ½·η²·gᵀHg
              ↑         ↑              ↑
            当前值   一阶：一定下降    二阶：曲率，可能把收益吃掉
```

- 一阶项 `−η‖g‖²` 永远是负的，说明**步子足够小时，一定下降**（这是 [微积分 1 第七节](#/aimodel/math-calc1) 的结论）；
- 二阶项 `+½η²gᵀHg` 是**正的**（H 正定），随 η 的**平方**增长。η 小时一阶占优，η 大了二阶会反超，函数反而上升。

**手算**：沿用 [极值与优化](#/math/optimization) 的 `f = (x² + 9y²)/2`，在 `(8, 1)`：`g = (8, 9)`，`H = diag(1, 9)`：

```text
f = 36.5，  ‖g‖² = 64 + 81 = 145，  gᵀHg = 64×1 + 81×9 = 793
f(η) = 36.5 − 145η + 396.5η²      （这个 f 本身是二次的，所以公式恰好精确）
```

| 学习率 η | 新的 f | 结论 |
| --- | --- | --- |
| 0.1 | 25.97 | 下降 |
| **0.183**（= 145/793，二次函数的最低点） | **23.24** | **沿此方向最好** |
| 0.3 | 28.69 | 下降变少 |
| 0.4 | **41.94** | **比 36.5 还高，上升了** |

下降条件是 `145 − 396.5η > 0`，即 `η < 0.366`。一般地，下降要求 `η < 2‖g‖²/(gᵀHg)`；如果曲率各向同性（`H = L·I`），就是我们熟悉的 **`η < 2/L`**。**学习率的上限，就是泰勒二阶项在“报复”一阶项。**

> [!NOTE] “L-光滑”的说法
> 论文里常说“损失是 L-光滑的”，意思是最大曲率不超过 L，于是 `f(y) ≤ f(x) + ∇f·(y−x) + (L/2)‖y−x‖²` 恒成立。取 `η = 1/L` 能保证每步至少下降 `‖g‖²/(2L)`。这就是上式的严格版。

## 五、牛顿法：直接跳到抛物线的谷底

既然二阶近似是一条抛物线，**为什么不直接跳到抛物线的最低点？** 一元时：

```text
f(x+Δ) ≈ f(x) + f′(x)Δ + ½f″(x)Δ²     对 Δ 求导并令为 0：  f′ + f″Δ = 0   →   Δ = −f′/f″
x ← x − f′(x) / f″(x)
```

多元时 `Δ = −H⁻¹g`（`H⁻¹` 是 Hessian 的逆矩阵，见 [线性方程组、逆矩阵与秩](#/math/linear-systems)）。对比梯度下降：GD 的步长是人定的 `η`，牛顿法的步长 `1/f″` 由**曲率自动决定**：越弯的地方步子越小。**二次函数上牛顿法一步到位。**

**手算**：最小化 `f(x) = eˣ − 2x`（最小点 `x = ln 2 = 0.6931`）。`f′ = eˣ − 2`，`f″ = eˣ`，从 `x₀ = 0` 开始：

```text
x₀ = 0：   f′ = −1，f″ = 1          x₁ = 0 − (−1)/1       = 1
x₁ = 1：   f′ = 0.7183，f″ = 2.7183  x₂ = 1 − 0.2642      = 0.7358
x₂ = 0.7358：f′ = 0.0871，f″ = 2.087  x₃ = 0.7358 − 0.0417 = 0.6941
x₃ → x₄ = 0.6931   （误差 4.0e-7）
```

误差依次是 `0.31 → 0.043 → 9e-4 → 4e-7`：**有效位数每步大约翻倍**（叫“二次收敛”）。对比 GD（η = 0.1）要 **63 步**才到 1e-6。

```python
import math

f1 = lambda x: math.exp(x) - 2          # f(x) = eˣ − 2x 的一阶导
f2 = lambda x: math.exp(x)              # 二阶导
x_star = math.log(2)                    # 真正的最小点 0.693147…

x = 0.0                                 # 牛顿法
for k in range(4):
    x = x - f1(x) / f2(x)
    print(f"newton step {k+1} x={x:.6f}  err={abs(x - x_star):.1e}")

x, n = 0.0, 0                           # 梯度下降 η=0.1
while abs(x - x_star) > 1e-6:
    x -= 0.1 * f1(x); n += 1
print("gd eta=0.1 needs", n, "steps")
# newton step 1 x=1.000000  err=3.1e-01
# newton step 2 x=0.735759  err=4.3e-02
# newton step 3 x=0.694042  err=9.0e-04
# newton step 4 x=0.693148  err=4.0e-07
# gd eta=0.1 needs 63 steps
```

> [!WARNING] 公平地说：η 选对了，GD 也很快
> 这个函数在最小点处曲率 `f″ = 2`，取 `η = 0.5 = 1/f″` 时 GD 只要 4 步。牛顿法的优势是**不用调 η**，自动适应每一点的曲率；代价在下面。

### 为什么大模型不用牛顿法

| 问题 | 说明 |
| --- | --- |
| **太大** | n 个参数，H 有 n² 个数。`n = 10⁸` 时要存 `10¹⁶` 个数，存不下 |
| **太慢** | 求 `H⁻¹` 要 n³ 量级的运算 |
| **不一定可用** | H 有负特征值（鞍点附近）时，牛顿步会指向**上坡**；需要加阻尼 |
| **噪声** | mini-batch 估计的二阶信息噪声更大 |

于是有各种“**拿到一点二阶信息，又不付全价**”的办法：

- **拟牛顿法 / L-BFGS**：只用最近几次的“位置差、梯度差”来拼凑出 `H⁻¹` 的近似，内存只与 `m·n` 成正比（m 约 10）。适合中小规模、确定性的问题（逻辑回归、经典优化）；
- **对角近似**：**Adam 的 `√v̂` 可以看成对曲率的粗略估计**（每个参数一个数，忽略参数间的相互作用）；
- **K-FAC、Shampoo 等**：按层把大矩阵拆成小矩阵的乘积（Kronecker 分解）再求逆，用于部分大规模训练，认识名字即可。

## 六、AI 里的应用

### 1. 用泰勒思想构造近似：GELU

Transformer 里常用的激活函数 GELU 定义为 `GELU(x) = x·Φ(x)`（`Φ` 是标准正态分布的累积概率，计算较贵）。实践中常用一个只含 `tanh` 和多项式的近似：

```text
GELU(x) ≈ 0.5·x·( 1 + tanh( √(2/π) · (x + 0.044715·x³) ) )
```

```python
import math
from scipy.stats import norm
for x in (-2, -1, 0.5, 1, 2):
    exact = x * norm.cdf(x)
    approx = 0.5 * x * (1 + math.tanh(math.sqrt(2 / math.pi) * (x + 0.044715 * x**3)))
    print(x, round(exact, 4), round(approx, 4))
# -2 -0.0455 -0.0454      -1 -0.1587 -0.1588      0.5 0.3457 0.3457
#  1  0.8413  0.8412       2  1.9545  1.9546
```

在这几个点上误差不超过 `2e-4`。要说明的是：括号里的 `0.044715·x³` 的系数是**拟合**出来的，不是严格的泰勒系数；但它体现了同样的想法：**用低次多项式（这里是 x 和 x³）去逼近一个难算的函数。**

### 2. 线性化：把非线性“局部看成线性”

在点 x 附近 `f(x+Δ) ≈ f(x) + ∇f·Δ`。这个“一阶近似”的用处很多：

- **灵敏度**：输入变化 Δ，输出大约变化 `∇f·Δ`。**对抗样本**（FGSM）正是沿 `sign(∇ₓL)` 方向给输入加一点点扰动，借一阶近似让损失上升最多；
- **反向传播**的雅可比矩阵，就是这个线性近似里的“斜率矩阵”；
- 激活函数在工作点附近 `σ(z) ≈ ½ + z/4`，说明小信号时 sigmoid 网络近似线性。

### 3. 损失曲面局部二次 → 学习率上限

在极小点附近，损失曲面就是二次的：`L(θ*+Δ) ≈ L(θ*) + ½ΔᵀHΔ`。第四节说过，**稳定训练需要 `η < 2/λ_max(H)`**，其中 `λ_max` 是 Hessian 的最大特征值（“最陡方向的曲率”，也叫 sharpness）。这解释了几个常见现象：

- 模型越大、数据越杂，曲面某些方向越陡，**能用的学习率越小**；
- **warmup** 的一个动机：训练初期曲率常较大且不稳定，先用小学习率；
- 有研究观察到，用较大学习率训练时 sharpness 会被“推”到 `2/η` 附近徘徊（“稳定性边缘”），这是一个仍在研究的现象，认识即可。

### 4. 误差估计

截断泰勒级数时，**误差大约就是被舍掉的第一项**。`e^0.5` 取到 2 阶，下一项 `x³/6 = 0.0208`，实际误差 0.0237，量级一致。拉格朗日余项给出严格形式：误差 `= f⁽ⁿ⁺¹⁾(ξ)/(n+1)! · xⁿ⁺¹`（ξ 是 0 到 x 之间的某个点）。工程上只需记住：**步长越小，误差按“阶数+1 次方”下降**，所以把步长缩小一半，一阶近似的误差缩小约 4 倍（二次项），二阶近似的误差缩小约 8 倍（三次项）。

## 自测：你真的懂了吗？

> [!QUESTION] 写出 `sin x` 在 0 附近的前两个非零项，并用它估算 `sin 0.2`。
> `sin x ≈ x − x³/6`。`sin 0.2 ≈ 0.2 − 0.008/6 = 0.2 − 0.001333 = 0.198667`，真值 0.198669。

> [!QUESTION] `f(x, y) = x² + 4y²`，在 `(1, 1)` 处，沿 `Δ = (−0.1, −0.1)` 走，分别用一阶和二阶泰勒近似 `f(1+Δx, 1+Δy)`，并与真值对比。
> `f = 5`，`∇f = (2x, 8y) = (2, 8)`，`H = diag(2, 8)`。一阶：`5 + (2×−0.1 + 8×−0.1) = 4`；二阶项 `½(2×0.01 + 8×0.01) = 0.05`，二阶近似 4.05。真值 `0.9² + 4×0.9² = 4.05`（二次函数，二阶近似恰好精确）。

> [!QUESTION] 为什么说“梯度下降只用一阶信息，所以步子不能太大”？
> 梯度下降依据的是一阶近似 `f(x+Δ) ≈ f(x) + ∇f·Δ`，只有 Δ 很小时才可信。步子大了，被忽略的二阶项 `½ΔᵀHΔ`（随步长平方增长）会反超一阶项，函数反而上升；学习率上限 `2/L` 就来自这里。

> [!QUESTION] 对 `f(x) = x²`，从 `x = 3` 出发做一步牛顿法，会到哪里？
> `f′ = 2x = 6`，`f″ = 2`，`x ← 3 − 6/2 = 0`。二次函数上牛顿法一步到达最小点。

> [!QUESTION] 为什么大模型训练不直接用牛顿法？列出两点。
> ① Hessian 有 n² 个元素，参数 n 达 10⁸ 以上时存不下；② 求逆要 n³ 的运算量太大。此外，H 在鞍点附近不正定，牛顿步可能指向上坡，mini-batch 估计的二阶信息还很嘈杂。所以实践里用 Adam（对角近似）、L-BFGS、K-FAC 等近似。
