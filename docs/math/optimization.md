# 极值与优化：从梯度下降到 Adam，再到约束优化

> [!ABSTRACT] 一句话版本
> - **训练 = 优化**：在“损失山谷”里找最低点。导数为 0 的点叫**驻点**，用**二阶导（Hessian）**判断它是谷底、山顶还是马鞍。
> - **凸函数**像一只碗：只有一个谷底，**局部最小 = 全局最小**。线性回归是凸的，神经网络不是。
> - **梯度下降**每步减去 `η×梯度`。在曲率为 L 的碗里，**步长必须小于 2/L** 才不发散；碗又扁又长（条件数大）时，路线会**之字形**。
> - **Momentum 攒速度、RMSProp 给每个参数单独调步长、Adam 两者合一**：它的第一步每个参数大约都走 `η`，与梯度大小无关。
> - **约束优化**：在“必须满足某条件”的前提下求最小，答案出现在**等高线与约束线相切**处，梯度互相平行（拉格朗日乘数法）。**L1 正则化的菱形有尖角，所以会产生稀疏。**

> [!NOTE] 先决条件
> 需要知道导数、梯度（[偏导数与梯度](#/math/gradient)）和链式法则（[链式法则与反向传播](#/math/chain-backprop)）。速成版见 [微积分 2：梯度下降](#/aimodel/math-calc2)，本页把“为什么这样”讲透。

## 一、极值与驻点：谷底长什么样

### 1. 一元：一阶、二阶条件

**问题**：`f(x) = x² − 4x + 3` 的最小值在哪？最低点一定是平的，即导数为 0（这样的点叫**驻点**）：

```text
f′(x) = 2x − 4 = 0   →   x = 2        f(2) = −1
```

但导数为 0 不保证是谷底，还可能是山顶，或者“只是平了一下”。用**二阶导数 `f″`（导数的导数，表示曲线往哪边弯）**判断：

| 驻点处 | 曲线形状 | 结论 |
| --- | --- | --- |
| `f″ > 0` | 向上弯（碗） | **极小值** |
| `f″ < 0` | 向下弯（帽子） | 极大值 |
| `f″ = 0` | 看不出 | 需要更多信息（如 `x³` 在 0 处是平台，不是极值） |

这里 `f″ = 2 > 0`，所以 x = 2 是谷底。

### 2. 多元：Hessian 与“正定 = 碗”

多个参数时，驻点条件是**梯度等于零向量**：`∇f = 0`。二阶信息要用 **Hessian 矩阵 H**（所有二阶偏导排成的方阵，读“黑塞”）：

```text
H = | ∂²f/∂x²    ∂²f/∂x∂y |       ∂²f/∂x² 读“f 对 x 的二阶偏导”
    | ∂²f/∂y∂x   ∂²f/∂y²  |
```

判断规则（`λ` 读“lambda”，是 H 的**特征值**，可以理解为沿几个“主方向”的弯曲程度，详见 [特征值与特征向量](#/math/eigen)）：

| H 的特征值 | 各方向弯曲 | 驻点类型 |
| --- | --- | --- |
| 全 > 0（**正定**） | 每个方向都向上弯 | **极小值**（碗底） |
| 全 < 0 | 每个方向都向下弯 | 极大值 |
| 有正有负 | 一个方向上弯、另一个下弯 | **鞍点**（马鞍） |

**手算**：

```text
f(x, y) = x² + 3y²      ∇f = (2x, 6y) = 0 → (0, 0)      H = | 2 0 |   特征值 2, 6 都 > 0 → 碗底
                                                            | 0 6 |
g(x, y) = x² − y²       ∇g = (2x, −2y) = 0 → (0, 0)    H = | 2  0 |   特征值 2, −2 一正一负 → 鞍点
                                                            | 0 −2 |
h(x, y) = x² + xy + y²  H = | 2 1 |   特征值 1, 3（numpy 算出）都 > 0 → 碗底（碗是“斜”的）
                            | 1 2 |
```

鞍点 `x² − y²`：沿 x 轴走是向上的碗，沿 y 轴走是向下的帽子，**梯度为 0 却不是最低点**。

**AI 里**：训练损失 `L(θ)` 的参数有几百万到几千亿个，Hessian 是一个同样大小的方阵，没法真的算；但“正定才是谷底”这个想法决定了我们怎么理解训练：停在 `∇L ≈ 0` 的地方时，要么是谷底，要么只是鞍点或平台。

## 二、凸函数：只有一个谷底的好世界

**凸函数**的定义很直观：**曲线上任取两点 A、B，连成的线段（弦）总在曲线上方（或重合）**。

```text
f( λa + (1−λ)b ) ≤ λ·f(a) + (1−λ)·f(b)       （0 ≤ λ ≤ 1；左边是曲线上的点，右边是弦上同一位置的点）
```

**手算**：`f(x) = x²`，`a = 0, b = 4, λ = 0.5`：左边 `f(2) = 4`，右边 `(0 + 16)/2 = 8`，`4 ≤ 8`，弦在曲线上方 ✓。而 `sin x` 在 `a = 0, b = π` 处，弦（值 0）在曲线（值 1）下方，所以不是凸的。

**为什么凸函数这么好？** 假设 A 是一个局部最小，但别处有个更低的点 B。看 A、B 之间的弦：靠近 A 的弦上各点，值都比 `f(A)` 低（因为弦的两端是 f(A) 和更小的 f(B)），而凸函数的曲线在弦下方，所以 A 的**任意近的邻居里都有比 A 更低的点**，这与“A 是局部最小”矛盾。结论：**凸函数的局部最小就是全局最小**，梯度下降只要学习率合适，一定能走到底。

| 问题 | 凸吗 | 说明 |
| --- | --- | --- |
| 线性回归的 MSE | **凸** | Hessian = `(2/n)·XᵀX`，对任意向量 v 有 `vᵀXᵀXv = ‖Xv‖² ≥ 0`，各方向不会下弯 |
| 逻辑回归的交叉熵 | **凸** | 同样只有一个谷底 |
| 神经网络的损失 | **非凸** | 例如把隐藏层两个神经元对调，函数不变，说明至少有多个“等价的谷底” |

神经网络的非凸地形里有**局部最小、鞍点、平原（梯度几乎为 0 的大片平地）**。实践经验是：高维空间里“坏的局部最小”不常见，更麻烦的是鞍点和平原，**噪声（SGD）和动量**能帮助离开它们。

## 三、梯度下降：为什么减去梯度，步子多大才行

### 1. 为什么是“减去梯度”

在当前点 θ 走一小步 Δ，用一阶近似（见 [泰勒展开](#/math/taylor)）：

```text
f(θ + Δ) ≈ f(θ) + ∇f · Δ         （点积；步子很小时可信）
```

想让 f 降得最多，就要让点积 `∇f · Δ` **最负**。步子长度固定时，点积 `= ‖∇f‖·‖Δ‖·cosφ`（φ 是两个向量的夹角）在 `φ = 180°` 即**与梯度正好反向**时最负。

**手算**：在某点 `∇f = (3, 4)`（长度 5），步长 0.1，试四个方向：

| 方向 Δ | `∇f·Δ` | 含义 |
| --- | --- | --- |
| `(−0.06, −0.08)`（反梯度） | **−0.5** | 降得最多 |
| `(0, −0.1)` | −0.4 | 有降 |
| `(−0.1, 0)` | −0.3 | 有降 |
| `(0.08, −0.06)`（垂直于梯度） | 0 | 沿等高线走，不升不降 |

### 2. 学习率的上限：在二次函数上看清楚

最简单的碗：`f(w) = ½·L·w²`（L 是**曲率**，越大碗越陡）。梯度 `f′(w) = L·w`，一步更新：

```text
w ← w − η·L·w = (1 − η·L)·w
```

**每一步，w 乘一个固定的倍数 `(1 − ηL)`。** 收敛的条件是这个倍数的绝对值小于 1：`|1 − ηL| < 1`，即

```text
0 < η < 2 / L
```

**手算**：`f(w) = 2w²`（所以 L = 4，上限 2/L = 0.5），从 `w = 1` 出发：

| 学习率 η | 倍数 `1−4η` | 前几步 w | 结果 |
| --- | --- | --- | --- |
| 0.1 | 0.6 | 1, 0.6, 0.36, 0.216, 0.130… | 平稳收敛 |
| 0.25（= 1/L） | 0 | 1, 0, 0, 0… | **一步到底** |
| 0.4 | −0.6 | 1, −0.6, 0.36, −0.216… | 来回跨过谷底，但在缩小 |
| 0.5（= 2/L） | −1 | 1, −1, 1, −1… | **永远震荡**，临界 |
| 0.6 | −1.4 | 1, −1.4, 1.96, −2.74… | **发散** |

这和 [微积分 2](#/aimodel/math-calc2) 里 `(w−3)²`（L = 2，上限 1）中 η = 1.1 发散是同一回事。**结论：曲率越大（越陡的地方），允许的学习率越小。**

### 3. 条件数与“椭圆峡谷”

真实的损失有很多个方向，每个方向有自己的曲率。以 `f(x, y) = (x² + 9y²)/2` 为例：x 方向曲率 1，y 方向曲率 9（又陡又窄）。梯度是 `(x, 9y)`，更新是 `x ← x − ηx`、`y ← y − 9ηy`，**两个方向各自乘自己的倍数**：

```text
x ← (1 − η)·x          y ← (1 − 9η)·y
```

- 步长上限由**最陡的方向**决定：`η < 2/9 ≈ 0.222`；
- 但 x 方向要靠同一个 η 前进，η 受限了，x 就走得慢。

取 η = 0.2，从 `(8, 1)` 出发：x 乘 `0.8`，y 乘 `1 − 1.8 = −0.8`：

```text
第 0 步 (8, 1)  → (6.4, −0.8) → (5.12, 0.64) → (4.096, −0.512) → (3.2768, 0.4096) → …
                  y 方向每步变号：之字形
```

取 η = 0.05：x 乘 0.95，y 乘 `0.55`：y 很快归零，x 每步只缩 5%，要“爬”很久。

最大曲率与最小曲率之比叫**条件数** `κ = λ_max / λ_min`（这里 9）。最好的单一步长是 `η = 2/(λ_max+λ_min)`（这里 0.2），此时每步误差最多缩小到 `(κ−1)/(κ+1)` 倍：

| 条件数 κ | 每步缩小到 | 误差降到千分之一约需 |
| --- | --- | --- |
| 9 | 0.80 | **31 步** |
| 100 | 0.980 | 345 步 |
| 1000 | 0.998 | 3454 步 |

**κ 越大越慢**，这就是特征尺度悬殊时要先做**标准化/归一化**、以及要用 **Momentum、Adam** 的原因（它们都在对付峡谷）。

```python
import numpy as np

lam = np.array([1.0, 9.0])                 # f(x,y) = (x² + 9y²)/2 的两个方向曲率

def run(eta, steps):
    p = np.array([8.0, 1.0])
    for _ in range(steps):
        p = p - eta * lam * p              # 梯度 = (x, 9y) = lam * p
    return p

print(run(0.2, 4))      # [3.2768 0.4096]   x 乘 0.8，y 乘 −0.8
print(run(0.05, 4))     # [6.51605    0.09150625]
print(run(0.2, 31))     # [ 0.00792282 -0.00099035]   31 步后约为起点的 1/1000
```

## 四、SGD 与 mini-batch：带噪声的梯度

完整梯度是所有样本梯度的**平均**。每步只抽 B 个样本（一个 **mini-batch**）算平均，得到的是**无偏估计**（平均下来对），但有**噪声**。

**手算**：4 个样本的梯度是 `2, 4, −2, 6`，真实平均 `2.5`。随机抽 2 个来平均，可能得到 `(2,4)→3`、`(−2,6)→2`、`(2,−2)→0`、`(4,6)→5`：围着 2.5 摇摆。

噪声大小（标准差）约为 `σ/√B`（σ 是单个样本梯度的标准差）：

| 批大小 B | 噪声（σ = 3 时） |
| --- | --- |
| 1 | 3 |
| 9 | 1 |
| 100 | 0.3 |

批大小翻 4 倍，噪声才减半。所以：**小批量便宜、噪声大，大批量贵、噪声小**。噪声不全是坏事：它帮助离开鞍点和尖锐的坑；但也意味着**学习率不能太大**，需要在训练后期调小（见第六节）。

## 五、Momentum、RMSProp、Adam：逐符号拆开

先约定：`g` 是当前步的（mini-batch）梯度，`θ` 是参数，`η` 是学习率，`t` 是第几步。

### 1. Momentum（动量）

```text
v ← β·v + g          θ ← θ − η·v          β 常取 0.9
```

`v` 是“速度”，β 是“惯性”（保留多少旧速度）。**手算**：梯度一直是 +1 时，`v` 会涨到 `1/(1−β) = 10`，步子放大 10 倍；梯度正负交替（1, −1, 1, −1…）时，`v = 1, −0.1, 0.91, −0.181, …`，大小在 `1/(1+β) = 0.53` 附近，**来回的分量被抵消**。所以它在“之字形”方向上减速震荡、在一致方向上加速。

### 2. RMSProp：每个参数一个步长

```text
s ← ρ·s + (1−ρ)·g²          θ ← θ − η · g / ( √s + ε )          ρ 常取 0.9~0.99，ε 常取 1e-8
```

`g²` 是逐元素平方；`s` 是“**梯度平方的滑动平均**”，`√s` 估计该参数梯度的**典型大小**（均方根，所以叫 RMS）。梯度总是很大的参数除以大数，步子变小；梯度总是很小的参数除以小数，步子变大。`ε` 防止除以 0。

### 3. Adam：动量 + RMSProp

```text
m ← β₁·m + (1−β₁)·g            一阶矩：梯度的滑动平均（动量）
v ← β₂·v + (1−β₂)·g²           二阶矩：梯度平方的滑动平均（RMSProp）
m̂ = m / (1 − β₁ᵗ)              偏差修正
v̂ = v / (1 − β₂ᵗ)              偏差修正
θ ← θ − η · m̂ / ( √v̂ + ε )
```

常用默认值：`β₁ = 0.9`，`β₂ = 0.999`，`ε = 1e-8`，`η = 1e-3`（`β₁ᵗ` 是 β₁ 的 t 次方）。**为什么要偏差修正？** m、v 从 0 开始，第一步 `m = 0.1·g` 只有真实梯度的 10%，估计偏小；除以 `1 − β₁ᵗ`（第一步为 0.1）后正好补回来，随着 t 增大修正自动消失。

**手算第一步**：`θ = (1.0, 2.0)`，梯度 `g = (0.5, −4)`（两个参数的梯度相差 8 倍），`η = 0.1`：

```text
m  = 0.1 × g          = (0.05, −0.4)             m̂ = m / 0.1     = (0.5, −4)
v  = 0.001 × g²       = (0.00025, 0.016)         v̂ = v / 0.001   = (0.25, 16)
√v̂ = (0.5, 4)
更新量 = η·m̂/√v̂ = 0.1 × (0.5/0.5, −4/4) = (0.1, −0.1)
θ = (1.0 − 0.1,  2.0 + 0.1) = (0.9, 2.1)
```

**看到了吗？** 两个梯度差 8 倍，两个参数却都只走了 `η = 0.1`。Adam 的步子**与梯度的绝对大小无关**，只取决于“方向是否一致”（m̂ 与 √v̂ 的比值，量级在 ±1 内）。这就是它对不同尺度的参数、不同层都“省心”的原因。

```python
import numpy as np
import torch

theta = np.array([1.0, 2.0]); g = np.array([0.5, -4.0])
eta, b1, b2, eps = 0.1, 0.9, 0.999, 1e-8

m = b1 * 0 + (1 - b1) * g                  # t = 1，m、v 从 0 开始
v = b2 * 0 + (1 - b2) * g**2
m_hat, v_hat = m / (1 - b1**1), v / (1 - b2**1)
print(theta - eta * m_hat / (np.sqrt(v_hat) + eps))     # [0.9 2.1]

p = torch.tensor([1.0, 2.0], requires_grad=True)       # 对照 PyTorch
opt = torch.optim.Adam([p], lr=0.1)
p.grad = torch.tensor([0.5, -4.0]); opt.step()
print(p.data)                                          # tensor([0.9000, 2.1000])
```

| 优化器 | 记住了什么 | 适用 |
| --- | --- | --- |
| SGD | 只有当前梯度 | 简单，学习率敏感 |
| SGD + Momentum | 梯度的“速度” | CNN 经典训练 |
| RMSProp | 梯度平方的平均 | RNN 等 |
| **Adam / AdamW** | 以上两者；AdamW 把权重衰减从梯度里**拆开** | **Transformer、大模型的默认选择** |

## 六、学习率调度与 warmup

固定学习率不是最优：前期想大步快走，后期想小步精修。常见调度由**两段**组成：

```text
warmup（线性升温）：lr(t) = η_max · t / T_w                           （t < T_w）
余弦衰减：          lr(t) = η_min + ½(η_max − η_min)(1 + cos(π·(t−T_w)/(T−T_w)))   （t ≥ T_w）
```

`T_w` 是预热步数，`T` 是总步数。**手算**：`η_max = 1e-3`，`η_min = 0`，`T_w = 1000`，`T = 10000`：

| 步数 t | 学习率 | 说明 |
| --- | --- | --- |
| 500 | 5e-4 | 预热到一半 |
| 1000 | 1e-3 | 峰值 |
| 5500 | 5e-4 | 衰减段的中点（cos 为 0，正好是峰值的一半） |
| 10000 | 0 | 衰减到底 |

**为什么需要 warmup？** 一开始参数是随机的，梯度很不靠谱；Adam 的二阶矩 `v` 还没攒够样本，估计很不准；此时大步前进容易把模型推到坏的区域甚至 NaN。先用很小的学习率“热身”，等统计量稳定了再升到峰值。大模型训练几乎都要预热。工程细节见 [训练神经网络](#/aimodel/training)。

## 七、约束优化：拉格朗日乘数法

### 1. 问题与直觉

有时候不能随便走：**在满足条件 `g(x,y) = 0` 的前提下，让 `f(x,y)` 最小**。

**例**：在直线 `x + y = 1` 上，找离原点最近的点。即最小化 `f = x² + y²`，约束 `g = x + y − 1 = 0`。

想象你沿着这条直线（约束曲线）走，同时看 f 的等高线（以原点为中心的圆）。**只要等高线与约束线“相交”（斜着穿过），你就还能沿线再走一点让 f 更小；最低点只能出现在等高线与约束线刚好“相切”处。** 相切意味着两者的法线方向平行，而 f 的法线就是 `∇f`、约束的法线是 `∇g`：

```text
∇f = λ · ∇g          （λ 读“lambda”，叫拉格朗日乘数，是一个待定的比例系数）
再加上约束本身：g = 0
```

### 2. 手算

```text
∇f = (2x, 2y)，∇g = (1, 1)
2x = λ,  2y = λ   →  x = y
约束 x + y = 1      →  x = y = 0.5，λ = 1，f = 0.5
```

最近点是 `(0.5, 0.5)`，距离 `√0.5 = 0.707`，与“点到直线的距离公式 `1/√2`”一致。

**再一个**：周长固定为 20 的矩形，面积最大是多少？最大化 `xy`，约束 `2x + 2y = 20`：`∇(xy) = (y, x) = λ(2, 2)` → `x = y`，再代入约束得 `x = y = 5`，面积 25（正方形）。

> [!TIP] 一个常见写法
> 把它们并成一个函数 `𝓛(x, y, λ) = f − λ·g`，对 x、y、λ 都求偏导并令为 0：对 x、y 求导得到 `∇f = λ∇g`，对 λ 求导得到约束 `g = 0`。三个方程三个未知数，机械地解就行。

**AI 里的出现**：

- **PCA**：最大化 `wᵀΣw`（投影后的方差），约束 `wᵀw = 1`（w 的长度为 1）。拉格朗日条件给出 `Σw = λw`，**恰好是特征向量方程**，所以主成分就是协方差矩阵的特征向量（[特征值与特征向量](#/math/eigen)）；
- **softmax / 最大熵**：约束 `Σpᵢ = 1`，推出指数形式；
- **SVM**：带不等式约束，用对偶形式（**KKT 条件**，认识即可）求解。

### 3. 正则化的两种视角：惩罚 vs 约束球

防止过拟合，要让权重 w 不要太大。有两种等价的写法：

```text
惩罚形式：  min  L(w) + α·R(w)         R 是 ‖w‖²（L2）或 Σ|wᵢ|（L1），α 是惩罚强度
约束形式：  min  L(w)    约束 R(w) ≤ r   （w 必须待在半径为 r 的“球”里）
```

用拉格朗日乘数法可知两者对应：**α 越大，球越小**（预算越紧）。关键在于球的形状：

- **L2**：球是**圆**（高维是球面），处处光滑。损失等高线与圆相切的点一般**不在坐标轴上**，各权重都**按比例缩小**但不为 0；对应的更新是 `w ← w(1 − ηα) − η∇L`，所以叫**权重衰减**；
- **L1**：球是**菱形**（高维是带尖角的多面体），尖角**恰好落在坐标轴上**。等高线向外扩张时，最先碰到的往往是尖角，那里某些权重**恰好为 0**，得到**稀疏**解。

**手算**：损失 `(w₁−3)² + (w₂−1)²`（无约束最优在 `(3, 1)`），预算：

```text
L1：|w₁| + |w₂| ≤ 2。在边界 w₁ + w₂ = 2 上用 ∇f = λ∇g：2(w₁−3) = λ，2(w₂−1) = λ
   → w₁ − 3 = w₂ − 1 → w₁ = w₂ + 2，代入 w₁ + w₂ = 2 → w₂ = 0，w₁ = 2    解为 (2, 0)：w₂ 恰好为 0
L2：w₁² + w₂² ≤ 4。把 (3, 1) 沿原点方向拉回球面：× 2/√10    解为 (1.897, 0.632)：两个都非零
```

## 八、对照表：优化概念与 AI

| 数学概念 | 在训练里的样子 |
| --- | --- |
| 驻点 `∇L = 0` | 训练停滞：可能是谷底、鞍点或平台 |
| Hessian 正定 | 谷底；有负特征值说明在鞍点，还有下降方向 |
| 凸 / 非凸 | 线性回归、逻辑回归凸（有保证）；神经网络非凸（靠经验与技巧） |
| `η < 2/L` | 学习率上限；曲率大的地方更容易炸 |
| 条件数 κ | 特征尺度悬殊 → 之字形；标准化、归一化、Adam 都是在缓解 |
| mini-batch 噪声 `σ/√B` | 批大小与学习率要一起调 |
| Momentum / RMSProp / Adam | 攒速度 / 每参数自适应步长 / 两者合一 |
| warmup + 衰减 | 大模型训练的标配学习率曲线 |
| 拉格朗日乘数法 | PCA 的特征向量、softmax 归一化、SVM 对偶 |
| L2 / L1 正则化 | 权重衰减 / 稀疏化（约束球是圆 / 菱形） |

## 自测：你真的懂了吗？

> [!QUESTION] 判断 `f(x, y) = x² − 2y² + 4` 的驻点类型，并说明理由。
> `∇f = (2x, −4y) = 0`，驻点 `(0, 0)`；`H = diag(2, −4)`，特征值一正一负，所以是**鞍点**：沿 x 方向像碗、沿 y 方向像帽子。

> [!QUESTION] 对 `f(w) = 5w²`，学习率 η = 0.3 能收敛吗？η = 0.5 呢？
> 曲率 L = 10，上限 `2/L = 0.2`。每步乘 `1 − 10η`：η = 0.3 时是 −2（发散）；η = 0.5 时是 −4，发散得更快。η = 0.1 时乘 0 一步到底；η = 0.15 时乘 −0.5 收敛。

> [!QUESTION] 为什么说 “Adam 第一步每个参数大约走 η”？这对不同尺度的参数意味着什么？
> 第一步 `m̂ = g`、`v̂ = g²`，所以更新量 `η·g/(|g|+ε) ≈ η·sign(g)`，与 g 的绝对大小无关。无论一个参数的梯度是 0.5 还是 −4（甚至 1e-5），它都按差不多的步长移动，所以不同层、不同尺度的参数不用单独调学习率。（后续步的比值仍在 ±1 左右的量级。）

> [!QUESTION] 用拉格朗日乘数法求：在 `x + 2y = 5` 上使 `x² + y²` 最小的点。
> `∇f = (2x, 2y) = λ(1, 2)` → `x = λ/2`，`y = λ`，所以 `y = 2x`。代入 `x + 2y = 5`：`5x = 5`，`x = 1`，`y = 2`，最小值 5。（点到直线的距离为 √5，与几何一致。）

> [!QUESTION] 为什么 L1 正则化会产生稀疏解，L2 不会？
> 约束形式下，L1 的约束区域是菱形，尖角落在坐标轴上；损失的等高线向外扩张时最先碰到的往往就是尖角，对应某些权重恰好为 0。L2 的约束区域是光滑的圆，相切点一般不在坐标轴上，所有权重都被按比例压小，但很少恰好为 0。

> [!QUESTION] 条件数 κ = 1000 的问题里，为什么只靠增大学习率没法加快收敛？
> 学习率上限由最陡的方向（最大曲率）决定，超过 `2/λ_max` 就发散；而最平的方向（最小曲率）在这个步长下每步只前进一点点，需要几千步。所以要靠预处理（标准化）、动量或 Adam 这类方法来改善“又陡又平”的结构。
