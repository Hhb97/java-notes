# 积分与期望：累加、面积与概率密度

> [!ABSTRACT] 一句话版本
> - **积分 = 把无穷多个无穷小的量加起来**。速度对时间积分得路程，高度对宽度积分得面积，密度对区间积分得**概率**。
> - **牛顿—莱布尼茨公式**：`∫ₐᵇ f(x)dx = F(b) − F(a)`，其中 `F` 是 `f` 的“反导数”。**求导和积分是互逆的**。
> - **概率密度**：曲线下的**面积**才是概率，总面积为 1；**期望** `E[X] = ∫ x·p(x) dx` 就是“加权平均”的连续版。
> - **Σ ↔ ∫**：离散用求和，连续用积分。softmax 的分母 `Σeᶻ` 就是离散版的**归一化常数（配分函数）**。
> - 复杂的积分算不出来时，**随机采样取平均**（蒙特卡洛）：误差按 `1/√N` 下降，与维度无关。训练里的 mini-batch，就是对“损失的期望”做的蒙特卡洛估计。

> [!NOTE] 先决条件
> 需要知道导数是“变化率”（[导数](#/math/derivative)）。概率的基本概念（期望、方差、正态分布）见 [概率与信息论入门](#/aimodel/math-prob)，本页把它们和“积分”接起来。

## 一、积分是无穷细的累加

### 1. 从速度到路程

匀速开车：速度 3 m/s，开 4 秒，路程 = 速度 × 时间 = 12 米。画成图，就是高 3、宽 4 的**矩形面积**。

**如果速度一直在变呢？** 比如 `v(t)` 从 0 开始逐渐加快。办法：**把时间切成很多小段，每一小段内当成匀速**，用“速度 × 这一小段时间”得到这段的路程，再全部加起来。切得越细，每段内越接近匀速，结果越准。这个“切成小矩形再相加”的过程，叫**黎曼和**。

### 2. 黎曼和：手算

问题：曲线 `y = x²` 在 `0 ≤ x ≤ 1` 下方的面积。把 `[0,1]` 分成 n 份，每份宽 `Δx = 1/n`（`Δ` 读“delta”，表示一小段），每个矩形取左端点的高度：

```text
n = 4：Δx = 0.25，左端点 x = 0, 0.25, 0.5, 0.75，高度 f(x) = x² = 0, 0.0625, 0.25, 0.5625
面积和 = (0 + 0.0625 + 0.25 + 0.5625) × 0.25 = 0.21875
```

```text
∫₀¹ x² dx = lim (n→∞) Σ f(xᵢ)·Δx = 1/3
```

符号：`∫` 是拉长的 “S”（Sum，求和）；`∫ₐᵇ` 表示从 a 到 b；`dx` 是“无穷小的宽度”；`f(x)dx` 是“高×宽”的小矩形面积。曲线在 x 轴**下方**的部分，面积算负的。

## 二、定积分、不定积分与牛顿—莱布尼茨公式

按定义用黎曼和算积分太累。有一条捷径：

- **反导数 `F`**：如果 `F′(x) = f(x)`，则 F 叫 f 的反导数（“导数的逆运算”）。比如 `x³/3` 的导数是 `x²`，所以 `x²` 的反导数是 `x³/3`。反导数不唯一（加任何常数导数不变），统一写成 `∫f(x)dx = F(x) + C`，叫**不定积分**；
- **牛顿—莱布尼茨公式**：

```text
∫ₐᵇ f(x) dx = F(b) − F(a)         （记作 [F(x)] 从 a 到 b）
```

**手算**：

```text
∫₀¹ x² dx = [x³/3]₀¹ = 1/3 − 0 = 1/3           与黎曼和的极限一致 ✓
∫₀^π sin x dx = [−cos x]₀^π = −(−1) − (−1) = 2
∫₀^∞ e^(−x) dx = [−e^(−x)]₀^∞ = 0 − (−1) = 1
```

**为什么成立（直觉）**：路程 `s(t)` 的导数是速度 `v(t)`；那么把速度一小段一小段加起来，当然就是 `s` 在两端的**差**，即 `s(b) − s(a)`。这说明**求导和积分互为逆运算**：对积分上限求导，得回被积函数：`d/dx ∫ₐˣ f(t)dt = f(x)`。

**常用积分表（认识即可）**：

| 函数 `f(x)` | 反导数 `F(x)` | 对应的求导 |
| --- | --- | --- |
| `xⁿ`（n ≠ −1） | `xⁿ⁺¹/(n+1)` | `(x³/3)′ = x²` |
| `1/x`（x > 0） | `ln x` | `(ln x)′ = 1/x` |
| `eˣ` | `eˣ` | 导数是自己 |
| `e^(−x)` | `−e^(−x)` | |
| `sin x` | `−cos x` | `(−cos x)′ = sin x` |
| `cos x` | `sin x` | |

> [!TIP] 在 AI 里你很少亲手算积分
> 但读论文要认得它：看到 `∫…dx`，把它想成“**对所有 x 加权求和**”。大多数复杂积分没有反导数，只能近似（第六节）。

## 三、概率密度：面积就是概率

### 1. 连续变量的概率

身高是连续的，“恰好等于 170.00000… cm”的概率是 0，没有意义。**有意义的是“落在一个区间里”的概率**。用一条曲线 `p(x)`（**概率密度函数**）来描述，规则：

```text
P(a ≤ X ≤ b) = ∫ₐᵇ p(x) dx          概率 = 曲线下 a 到 b 之间的面积
p(x) ≥ 0，且 ∫ p(x) dx = 1            密度非负，总面积为 1
```

> [!WARNING] 密度不是概率
> `p(x)` 本身可以大于 1。例如 X 在 `[0, 0.5]` 上均匀分布，`p(x) = 2`（宽 0.5 × 高 2 = 面积 1）。**只有“密度 × 宽度”（面积）才是概率。**

**手算**：均匀分布 `U(0,2)`，`p(x) = 0.5`（`0 ≤ x ≤ 2`）。`P(0.5 ≤ X ≤ 1.5) = 0.5 × (1.5−0.5) = 0.5`。

### 2. 期望与方差

离散时期望是“值 × 概率”的求和；连续时把求和换成积分，概率换成 `p(x)dx`：

```text
离散： E[X] = Σ xᵢ·pᵢ                    连续： E[X] = ∫ x·p(x) dx
方差：  Var(X) = E[(X − μ)²] = E[X²] − μ²       （μ = E[X]；μ 读“mu”）
```

**手算**：密度 `p(x) = 2x`（`0 ≤ x ≤ 1`）。先检查总面积：`∫₀¹ 2x dx = [x²]₀¹ = 1` ✓。

```text
P(X ≤ 0.5) = ∫₀^0.5 2x dx = 0.5² = 0.25
E[X]   = ∫₀¹ x·2x dx   = ∫₀¹ 2x² dx = 2/3 = 0.667
E[X²]  = ∫₀¹ x²·2x dx  = ∫₀¹ 2x³ dx = 1/2
Var(X) = 1/2 − (2/3)² = 1/2 − 4/9 = 1/18 = 0.0556
```

密度偏向右边（`x` 大的地方密度高），所以期望 2/3 比中点 0.5 大。

## 四、高斯分布：为什么系数是 1/√(2πσ²)

**高斯（正态）分布**的密度：

```text
p(x) = 1/√(2πσ²) · exp( −(x − μ)² / (2σ²) )
```

`μ`（均值）决定中心，`σ`（标准差，读“sigma”）决定宽窄，`exp(u)` 就是 `eᵘ`。钟形来自 `exp(−(x−μ)²/(2σ²))`：离中心越远，指数越负，值越小。

**那个奇怪的系数 `1/√(2πσ²)` 是干什么的？** 它是**归一化常数**：保证总面积恰好是 1。只看钟形部分：

```text
∫ exp(−x²/(2σ²)) dx（从 −∞ 到 +∞） = σ·√(2π)          （一个著名结果，这里不推导）
```

数值核对（σ = 1 时钟形的总面积）：`∫ e^(−x²/2) dx = 2.5066 = √(2π)`。所以要让面积变成 1，必须**除以 2.5066，即乘以 `1/√(2π) = 0.3989`**。σ 变成 2 时，钟形变宽 2 倍，面积也变成 2 倍（5.0133），所以系数里还要多除一个 σ：

| σ | 钟形部分的面积 | 归一化系数 | 峰高 |
| --- | --- | --- | --- |
| 1 | 2.5066 | `1/2.5066 = 0.3989` | 0.399 |
| 2 | 5.0133 | `1/5.0133 = 0.1995` | **0.199（更矮）** |

**曲线越宽就必须越矮**，因为总面积固定为 1。

## 五、离散与连续的对应：Σ ↔ ∫

| | 离散 | 连续 |
| --- | --- | --- |
| 分布 | 概率 `pᵢ`（质量函数） | 密度 `p(x)` |
| 归一化 | `Σ pᵢ = 1` | `∫ p(x) dx = 1` |
| 期望 | `Σ xᵢ pᵢ` | `∫ x p(x) dx` |
| 例子 | 骰子：`(1+2+…+6)/6 = 3.5` | 高斯、均匀分布 |

**softmax 的分母就是配分函数**：softmax 把任意分数 `zᵢ` 变成概率：

```text
pᵢ = e^(zᵢ) / Z，      Z = Σⱼ e^(zⱼ)
z = (2, 1, 0)：  Z = 7.389 + 2.718 + 1 = 11.107，  p = (0.665, 0.245, 0.090)
```

做法是“**先写一个正数（没归一化），再除以总和 Z，让总和为 1**”。`Z` 叫**配分函数**（partition function）。连续版本完全一样：

```text
p(x) = e^(−E(x)) / Z，      Z = ∫ e^(−E(x)) dx
E(x) = (x−μ)²/(2σ²) 时，Z = √(2πσ²)   →   就是高斯分布
```

所以：**高斯分布的归一化常数，就是连续版的 softmax 分母。** 离散时 Z 是求和，容易算；连续时 Z 是积分，往往算不出来——这是很多概率模型（能量模型等）训练困难的根源，也是下面蒙特卡洛登场的原因。

## 六、数值积分与蒙特卡洛：用随机采样估计期望

### 1. 数值积分与“维数灾难”

一维积分可以像黎曼和那样切成网格（还有更精确的梯形法、辛普森法，`scipy.integrate.quad` 就是这类）。但 d 维空间里，每个方向取 100 个点，要算 `100ᵈ` 个点：**d = 10 时就是 10²⁰ 个，没法做**。而神经网络里的积分常常是几百几千维。

### 2. 蒙特卡洛：随机抽样取平均

关键观察：期望本身就是积分，反过来，**积分可以写成期望，然后用样本平均去估计**：

```text
E[f(X)] = ∫ f(x)·p(x) dx  ≈  (1/N) · Σ f(xᵢ)，      xᵢ 是从 p 里随机抽出的 N 个样本
```

**手算**：`∫₀¹ x² dx = E[X²]`，其中 `X` 在 `[0,1]` 上均匀分布。随机抽 5 个数 `0.2, 0.9, 0.5, 0.7, 0.1`：

```text
x²：0.04, 0.81, 0.25, 0.49, 0.01       平均 = 1.6 / 5 = 0.32        真值 0.3333（只用 5 个样本，已经很近）
```

```python
import numpy as np
from scipy import integrate

print(integrate.quad(lambda x: x**2, 0, 1)[0])          # 0.33333333333333337  数值积分

n = 10; dx = 1 / n; xs = (np.arange(n) + 0.5) * dx
print((xs**2).sum() * dx)                              # 0.3325               中点黎曼和

rng = np.random.default_rng(0)                         # 蒙特卡洛：单次运行
for N in (100, 10_000, 1_000_000):
    x = rng.random(N)
    print(N, (x**2).mean())                            # 100 0.3925   10000 0.3327   1000000 0.3336

rng = np.random.default_rng(1)                         # 每个 N 重复 200 次，看均方根误差
for N in (10, 100, 1000, 10_000, 100_000):
    err = [(rng.random(N) ** 2).mean() - 1 / 3 for _ in range(200)]
    print(N, round(float(np.sqrt(np.mean(np.square(err)))), 5), round(0.298 / np.sqrt(N), 5))
# 10 0.09334 0.09424 / 100 0.03079 0.0298 / 1000 0.00932 0.00942 / 10000 0.00262 0.00298 / 100000 0.00088 0.00094
```

第一列是实测误差，第二列是理论值 `σ/√N`（这里 `σ = 0.298` 是 `X²` 的标准差）。**误差按 `1/√N` 下降：样本多 100 倍，误差只缩小 10 倍。** 单次运行有随机性（N = 100 那次偏了 0.06，约两个标准差，属正常）。

## 七、AI 里的应用

### 1. 损失函数是“期望”，mini-batch 是它的蒙特卡洛估计

我们真正想最小化的是**对所有可能数据的平均损失**：

```text
L(θ) = E_{(x,y)~数据分布}[ ℓ(f_θ(x), y) ] = ∫ ℓ(f_θ(x), y)·p(x,y) dx dy
```

这个积分无法算，因为我们不知道真实分布 `p`，只有一个数据集。于是用样本平均代替（经验风险 `1/n·Σℓᵢ`）。更进一步，梯度也是期望：`∇L = E[∇ℓ]`，每步抽一个 mini-batch 取平均 `∇L ≈ (1/B)·Σ∇ℓᵢ`，**就是对期望梯度的一次蒙特卡洛估计**。这解释了 [极值与优化](#/math/optimization) 里的噪声规律：**噪声 ∝ 1/√B**，批大小翻 4 倍噪声才减半。

### 2. 归一化

softmax 的分母（离散的配分函数）、高斯的 `1/√(2πσ²)`（连续的归一化常数），都是“让总和/面积为 1”。语言模型每个位置输出的就是词表上的一个归一化分布。

### 3. VAE 与扩散模型里的积分（认识）

- **VAE** 想要“生成 x 的概率”：`p(x) = ∫ p(x|z)·p(z) dz`，对所有潜变量 `z` 积分，算不出来。所以改成优化它的一个**下界（ELBO）**，其中的期望 `E_{z~q}[log p(x|z)]` 用**采样**估计；
- **扩散模型**：训练时对“噪声强度”和“噪声样本”都做随机抽样，损失是对它们的期望，用 mini-batch 做蒙特卡洛；生成时逐步去噪，可以理解为对一连串小变化做“累加”（积分）。

### 4. 重参数化技巧（一句话直觉）

要对 `E_{z~N(μ,σ²)}[f(z)]` 关于 μ、σ 求梯度，但“从分布里抽一个 z”这一步没法求导。办法：把随机性单独拿出来，**写成 `z = μ + σ·ε`，其中 `ε ~ N(0,1)`**。随机性全在 ε 里（它不依赖参数），z 对 μ、σ 是普通的可导函数：`∂z/∂μ = 1`，`∂z/∂σ = ε`。例如 `μ = 1, σ = 0.5, ε = 0.8`：`z = 1.4`，`∂z/∂μ = 1`，`∂z/∂σ = 0.8`。

```python
import torch
torch.manual_seed(0)
mu = torch.tensor(1.0, requires_grad=True)
sigma = torch.tensor(0.5, requires_grad=True)
eps = torch.randn(100_000)            # 随机性全部放在 ε ~ N(0,1) 里
z = mu + sigma * eps                   # 重参数化：z ~ N(mu, sigma²)
loss = (z ** 2).mean()                 # 估计 E[z²] = mu² + sigma²
loss.backward()
print(loss.item(), mu.grad.item(), sigma.grad.item())
# 1.2481756210327148 1.9975543022155762 0.9975937604904175
```

理论值：`E[z²] = μ² + σ² = 1.25`，`∂/∂μ = 2μ = 2`，`∂/∂σ = 2σ = 1`；10 万个样本估计的结果与之吻合到 0.3% 左右。VAE 就靠这个技巧让梯度穿过“采样”这一步。

## 自测：你真的懂了吗？

> [!QUESTION] 用牛顿—莱布尼茨公式算 `∫₁³ 2x dx`，并用“梯形面积”验证。
> 反导数 `x²`，`[x²]₁³ = 9 − 1 = 8`。几何：`y = 2x` 在 x = 1 到 3 之间是梯形，上底 6、下底 2、高 2，面积 `(2+6)×2/2 = 8` ✓。

> [!QUESTION] 密度 `p(x) = 3x²`（`0 ≤ x ≤ 1`）是合法的概率密度吗？求 `E[X]`。
> 总面积 `∫₀¹ 3x² dx = [x³]₀¹ = 1`，非负，合法。`E[X] = ∫₀¹ x·3x² dx = ∫₀¹ 3x³ dx = 3/4 = 0.75`。

> [!QUESTION] 为什么概率密度可以大于 1，而概率不可以？
> 密度是“单位宽度上的概率”，概率是**密度 × 宽度（面积）**。如果区间很窄（比如宽 0.5），密度可以是 2，面积仍然是 1。概率是面积，必须在 0 到 1 之间；密度只是曲线的高度。

> [!QUESTION] 高斯分布的 σ 从 1 变成 2，峰高怎么变？为什么？
> 峰高 `1/√(2πσ²)` 减半（0.399 → 0.199）。σ 变大曲线变宽，钟形部分的面积随 σ 成比例增大，要保持总面积 1，系数必须除以 σ，所以变矮。

> [!QUESTION] 想把蒙特卡洛的误差再缩小到原来的 1/10，样本数要增加多少倍？
> 误差 ∝ `1/√N`，缩小 10 倍需要 `√N` 增大 10 倍，即 N 增加 **100 倍**。（所以 mini-batch 里“批量翻 4 倍，噪声减半”。）

> [!QUESTION] 重参数化技巧解决了什么问题？
> 梯度无法穿过“从分布里随机抽样”这一步。把 `z ~ N(μ,σ²)` 改写成 `z = μ + σε`（ε ~ N(0,1) 的随机性与参数无关），z 就成了 μ、σ 的可导函数，梯度可以顺着它传回 μ、σ。
