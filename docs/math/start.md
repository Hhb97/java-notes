# AI 数学学习地图：符号、函数与怎么学

> [!ABSTRACT] 一句话版本
> - AI 里的数学不是三门互不相干的课，而是**同一条流水线**：线性代数负责“算出预测”，概率负责“量出错得多离谱”，微积分负责“知道每个旋钮该往哪拧”。
> - 公式是**一种语言**：认识十几个希腊字母、`Σ`、`Π`、下标上标，就能“念”出绝大多数论文公式。
> - `eˣ` 和 `ln x` 是 AI 里出场最多的函数：**对数把连乘变成连加**，所以概率、损失、softmax 里到处是它。
> - 读公式有套路：**先数符号，再由内向外念，最后代一组小数字**。
> - 你不需要成为数学家，只需要能**看懂、会手算小例子、会用代码验证**。

## 一、为什么 AI 需要数学：把一个神经元从头走到尾

先别怕“数学”两个字。我们拿**一个最小的神经元**，从输入走到损失，看每一步到底用了什么数学。

设有一个样本，输入是两个特征 `x = (2, 1)`（比如“学习时长 2 小时、睡眠 1 档”），标签 `y = 1`（表示“通过考试”）。神经元有两个权重 `w = (0.8, −0.4)` 和一个偏置 `b = 0.1`。

逐步手算：

```text
① 线性部分（点积）：  z = w·x + b = 0.8×2 + (−0.4)×1 + 0.1 = 1.6 − 0.4 + 0.1 = 1.3
② 压成概率（sigmoid）：ŷ = σ(z) = 1 / (1 + e^(−1.3)) ≈ 0.786      ← 模型说“通过的概率约 78.6%”
③ 损失（交叉熵）：   L = −ln ŷ = −ln 0.786 ≈ 0.241                  ← 答案是“通过”，预测 0.786，错得不多
```

“损失”就是把“错得多离谱”变成**一个数**；若模型只给了 `ŷ = 0.1`，损失会涨到 `−ln 0.1 ≈ 2.303`。

接下来才是“学习”：我们想知道 **`w₁` 调大一点，`L` 会变大还是变小、变多少**。这个问题的答案叫 **偏导数 `∂L/∂w₁`**，由微积分给出；有了它，就能写 `w₁ ← w₁ − η·∂L/∂w₁`，一点点把损失压低。

| 环节 | 用到的数学 | 对应页面 |
| --- | --- | --- |
| 把数据装成 `x`、权重装成 `w`；`z = w·x + b` | 向量、点积、矩阵乘法 | 向量、矩阵、张量 |
| `σ(z)`、`ln` | 函数、指数、对数 | 本页、极限 |
| `L = −ln ŷ` | 概率、期望、信息量 | 积分与期望 |
| `∂L/∂w`、`w ← w − η∇L` | 导数、偏导、链式法则、优化 | 导数、梯度、反向传播、优化 |

GPT 这样的大模型有几千亿个参数，但每个参数面对的都是这一幕：**前向算预测、算损失、求梯度、更新自己**。吃透这个小例子，大模型只是同样的事做了很多遍。

## 三、数学语言速成

### 1. 变量、函数、参数

- **变量**：会变的量，通常用 `x、y、z`。在 AI 里 `x` 常是输入，`y` 是真实答案，`ŷ`（念“y 帽”）是模型的预测。
- **函数**：一台“输入 → 输出”的机器，写成 `y = f(x)`。念作“y 等于 f 括号 x”，不是“f 乘以 x”。
- **参数**：函数里**固定下来、但可以被训练调整**的数，如 `y = w·x + b` 里的 `w`（权重）和 `b`（偏置）。区分一下：`x` 是**喂进去**的，`w、b` 是**学出来**的。

### 2. 下标与上标

| 写法 | 念法 | 含义 |
| --- | --- | --- |
| `xᵢ` | x 下标 i | 第 i 个 x，如 `x₁, x₂, x₃` |
| `x²` | x 的平方 | 上标是**幂**，`3² = 9` |
| `x⁽ⁱ⁾` | x 上标括号 i | 第 i 个样本（括号提醒：这不是幂） |
| `Aᵀ` | A 转置 | 行列互换，向量、矩阵页详谈 |

`a²` 与 `aᵢ` 要看清：一个是平方，一个是“第 i 个”，初学者最易混。

### 3. 求和 Σ 与连乘 Π

`Σ`（希腊字母 sigma，念“求和”）表示**把一串数加起来**：

```text
Σᵢ₌₁ⁿ xᵢ  =  x₁ + x₂ + … + xₙ          （i 从 1 数到 n，每个 i 取一项，全部相加）
```

**手算例子 1**：设 `x = (2, 5, 3)`，则

```text
Σᵢ₌₁³ xᵢ = 2 + 5 + 3 = 10                平均值 = 10 ÷ 3 ≈ 3.33
Σᵢ₌₁³ xᵢ² = 4 + 25 + 9 = 38              （先平方再加，不是 10² = 100！）
```

`Π`（希腊字母 pi 的大写，念“连乘”）是**把一串数乘起来**：

```text
Πᵢ₌₁³ pᵢ  =  p₁ × p₂ × p₃        例：p = (0.9, 0.8, 0.5)  →  0.9 × 0.8 × 0.5 = 0.36
```

均方误差里的 `L = (1/n)·Σ (ŷᵢ − yᵢ)²` 就是“每个样本的误差平方，加起来再取平均”。

> [!WARNING] 常见误区：Σ 不是“加一次”
> `Σᵢ₌₁ⁿ (xᵢ)²` 的括号里有 `i`，所以**每次 i 变一下，括号里的值就变一下**。如果括号里根本没有 `i`，比如 `Σᵢ₌₁ⁿ c`，结果就是 `n·c`。

### 4. 希腊字母表（在 AI 里的约定）

字母不是随便用的，论文里有“约定俗成”的意思，认熟它们能省很多力气：

| 字母 | 念法 | AI 里常见含义 |
| --- | --- | --- |
| `α` `β` `γ` | alpha beta gamma | `α` 注意力权重/斜率；`β₁, β₂` Adam 的动量系数；`γ` 折扣因子、LayerNorm 缩放 |
| `δ` | delta | 误差信号、微小变化 |
| `ε` | epsilon | **极小的正数**，如防止除以 0 的 `1e-8` |
| `η` | eta | **学习率**（本分类统一用它） |
| `θ` | theta | **全体参数**的统称；也可以是夹角 |
| `λ` | lambda | 正则化系数；特征值 |
| `μ` `ν` `ρ` | mu nu rho | `μ` 均值；`ν` 少见（某些优化器的累计量）；`ρ` 相关系数 |
| `π` | pi | 圆周率 3.14159…；强化学习里的策略 |
| `σ` | sigma | 标准差；也是 **sigmoid** 函数的名字 |
| `τ` | tau | softmax 的温度 |
| `φ` `ω` | phi omega | `φ` 特征映射/激活；`ω` 权重、角频率 |
| `Δ` | Delta | **一个有限的变化量**，如 `Δx` |
| `∇` | nabla | **梯度**：把所有偏导数打包成向量 |
| `∂` | “偏” | **偏导数**：多元函数里只动一个变量 |

> [!TIP] 同一个符号在不同论文里含义可能不同（`σ` 既是标准差又是 sigmoid），**先看作者有没有定义**。

## 四、指数与对数：AI 里出场最多的一对函数

### 1. 指数：连乘的简写

`2³ = 2×2×2 = 8`，上标 3 表示“乘三次”。指数还可以是负数、小数：

```text
2⁰ = 1          2⁻¹ = 1/2 = 0.5          2^0.5 = √2 ≈ 1.414
```

数学里有一个特别重要的底数，叫 **`e ≈ 2.71828`**（欧拉数，念“e”）。它的来历在[极限](#/math/limit)一页会用“复利越算越勤”讲清；在[导数](#/math/derivative)一页你会看到它的招牌性质：**`eˣ` 的导数还是它自己**。现在只需记住：`eˣ`（也写 `exp(x)`）是**永远为正**、**增长越来越快**的函数。

### 2. 对数：指数的“反过来问”

`ln x`（自然对数，念“ln x”）回答的是：**e 的几次方等于 x？**

```text
e^1 ≈ 2.718 → ln 2.718 = 1        e^2 ≈ 7.389 → ln 7.389 = 2        ln 1 = 0（因为 e⁰ = 1）
```

`eˣ` 与 `ln x` 是**互逆**的：先指数再对数，等于什么都没做，`ln(eˣ) = x`；反过来 `e^(ln x) = x`（`x > 0`）。

数值表（自己用计算器或 Python 核对）：

| x | `eˣ` | `e⁻ˣ` | `ln x` |
| --- | --- | --- | --- |
| 0.5 | 1.649 | 0.607 | −0.693 |
| 1 | 2.718 | 0.368 | 0 |
| 2 | 7.389 | 0.135 | 0.693 |
| 3 | 20.09 | 0.0498 | 1.099 |
| 5 | 148.4 | 0.00674 | 1.609 |
| 10 | 22026 | 0.0000454 | 2.303 |

看表有三个观察：`eˣ` 涨得**极快**（x 从 5 到 10，函数值涨了约 148 倍）；`ln x` 涨得**极慢**（x 从 5 到 10，只多了 0.69）；`ln x` 在 `0 < x < 1` 时是**负数**，且 x 越接近 0，越往负无穷去（`ln 0.01 ≈ −4.605`）。

### 3. 对数最重要的性质：乘变加

```text
ln(a × b) = ln a + ln b          ln(aᵇ) = b × ln a          ln(a ÷ b) = ln a − ln b
```

**手算例子 2**：验证 `ln 6 = ln 2 + ln 3`。查表 `ln 2 ≈ 0.693`、`ln 3 ≈ 1.099`，相加得 `1.792`；直接算 `ln 6 ≈ 1.792`。一致。

再用在“连乘”上：`0.9 × 0.8 × 0.5 = 0.36`，取对数得

```text
ln 0.9 + ln 0.8 + ln 0.5 = −0.1054 − 0.2231 − 0.6931 = −1.0217 = ln 0.36     ✓
```

### 4. 为什么 AI 到处是 log

1. **概率连乘变连加**。一个模型对 1000 个样本的预测概率连乘，会得到一个小得离谱的数；取对数后就变成一千个数相加，**好算、好求导**（这叫“对数似然”）。
2. **数值不会下溢**。比如 2000 个 `0.5` 连乘，真实值 `0.5²⁰⁰⁰` 小到机器放不下，结果显示为 `0.0`；而 `Σ ln 0.5 = −1386.29` 是个很正常的数（代码见下）。
3. **交叉熵 `−ln p`** 对“很不自信的正确答案”惩罚极重：`p = 1` 时为 0，`p = 0.5` 时 0.693，`p = 0.1` 时 2.303，`p = 0.01` 时 4.605。
4. **softmax 与数值稳定**：`softmax` 要先算 `eˣ`，`e¹⁰⁰⁰` 会溢出；“减去最大值”的 log-sum-exp 技巧在[极限](#/math/limit)一页手算。

> [!WARNING] 常见误区
> `ln(a + b)` **不等于** `ln a + ln b`。对数只对**乘法**友好，对加法没有简单公式。初学者最容易在这里写错。

## 六、怎么读公式：三步法

拿到一个陌生公式，不要从头念到尾，按三步走：

1. **数符号**：列出每个符号是**标量、向量还是矩阵**，是**已知的**（数据）、**要学的**（参数）还是**算出来的**。没定义的符号，去找它的定义。
2. **由内向外念**：最里层括号先念，再往外。把每一块翻成人话。
3. **代小数字**：给每个符号赋一个能心算的值，把公式算一遍，看结果符不符合直觉。

**手算例子 3**：读交叉熵 `L = −Σᵢ yᵢ · ln ŷᵢ`。

```text
第 1 步（数符号）：yᵢ 是真实答案（独热向量），ŷᵢ 是模型给第 i 类的概率；Σ 对所有类别求和
第 2 步（念）：   把“真实答案”与“对数概率”逐位相乘，加起来，取负
第 3 步（代数）：设三类，y = (0, 1, 0)，ŷ = (0.2, 0.7, 0.1)
                 Σ yᵢ ln ŷᵢ = 0×ln0.2 + 1×ln0.7 + 0×ln0.1 = ln 0.7 ≈ −0.357
                 L = −(−0.357) = 0.357
```

结论：独热向量里只有“正确类别”那一项不为 0，所以交叉熵其实就是 **`−ln(模型给正确答案的概率)`**。与第一节里的 `L = −ln ŷ` 完全一致。

## 八、动手：用 Python 验证本页的数字

```python
import numpy as np

x = np.array([2.0, 1.0]); w = np.array([0.8, -0.4]); b = 0.1
z = w @ x + b                      # 线性代数：前向
y_hat = 1 / (1 + np.exp(-z))       # 非线性：sigmoid
loss = -np.log(y_hat)              # 概率：标签 y=1 时的交叉熵
print(f"z={z:.3f}  y_hat={y_hat:.3f}  loss={loss:.3f}")
# z=1.300  y_hat=0.786  loss=0.241

# 乘变加：2000 个概率 0.5 连乘 vs 取 log 后求和
p = np.full(2000, 0.5)
print(np.prod(p), np.sum(np.log(p)))
# 0.0 -1386.2943611198907
```

第二段是“对数不下溢”的实证：连乘被机器当成了 `0.0`，取对数后求和仍然正常。

## 九、自测

：你真的懂了吗？

> [!QUESTION] 计算 `Σᵢ₌₁⁴ i²`，再说说它和 `(Σᵢ₌₁⁴ i)²` 一样吗？
> `1 + 4 + 9 + 16 = 30`。而 `(1+2+3+4)² = 10² = 100`。**两者不同**：前者先平方后求和，后者先求和后平方。

> [!QUESTION] 已知 `ln 2 ≈ 0.693`，不查表求 `ln 8` 与 `ln 0.5`。
> `ln 8 = ln(2³) = 3 × 0.693 = 2.079`；`ln 0.5 = ln(2⁻¹) = −0.693`。这里用的是 `ln(aᵇ) = b·ln a`。

> [!QUESTION] 模型给“正确答案”的概率分别是 0.9 和 0.1，交叉熵损失各是多少？说明什么？
> `−ln 0.9 ≈ 0.105`，`−ln 0.1 ≈ 2.303`。越不自信地答对（概率低），损失越重；0.1 的损失是 0.9 的 20 多倍。

> [!QUESTION] 计算 `ReLU(−3)`、`ReLU(2)`、`σ(0)`。
> `ReLU(−3) = max(0, −3) = 0`；`ReLU(2) = 2`；`σ(0) = 1/(1+e⁰) = 1/2 = 0.5`。
