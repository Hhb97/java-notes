# 特征值与特征向量：PCA 与谱的直觉

> [!ABSTRACT] 一句话版本
> - **特征向量**：矩阵是一台“变换机”，绝大多数方向都会被它拧歪，但有几个特殊方向，向量沿着它们走只会被**拉长或压短、不会转弯**；拉伸的倍数叫**特征值**。公式 `Av = λv`。
> - **手算**：特征值是 `det(A − λI) = 0` 的根，2×2 矩阵就是解一个一元二次方程。
> - **幂**：反复乘同一个矩阵，每个特征方向各自乘 `λⁿ`。`|λ| > 1` 爆炸，`|λ| < 1` 消失，这是 RNN 梯度爆炸/消失的数学根源。
> - **对称矩阵最乖**：特征值全是实数，特征向量互相垂直，`A = QΛQᵀ`。协方差矩阵、Hessian 都是对称矩阵。
> - **PCA**：对协方差矩阵求特征向量，最大特征值对应的方向就是数据“最分散”的方向。

> [!NOTE] 先决条件
> 建议先读 [矩阵：线性变换与矩阵乘法](#/math/matrices)（矩阵是变换）和 [线性方程组、逆矩阵与秩](#/math/linear-systems)（行列式、可逆）。想先看速成版可以读 [线性代数 2：特征值、SVD 与 PCA](#/aimodel/math-la2)，本页是它的“慢放版”。

```text

v₁ = (1, 1)：  A·v₁ = (4×1 + 1×1, 2×1 + 3×1) = (5, 5)  = 5 × (1, 1)
v₂ = (1, −2)： A·v₂ = (4×1 + 1×(−2), 2×1 + 3×(−2)) = (2, −4) = 2 × (1, −2)
```

`e` 本来指向正右方，变换后歪向了右上方，**方向变了**。但 `v₁` 和 `v₂` 很特别：变换后仍在原来那条直线上，只是长度变成了 5 倍和 2 倍。

### 1. 定义

```text
A v = λ v
```

- `A`：一个**方阵**（行数 = 列数）；
- `v`：一个**非零向量**，叫**特征向量**（eigenvector；eigen 在德语里是“自己的、固有的”）；
- `λ`（读作“lambda”）：一个数，叫**特征值**（eigenvalue）。

读法：矩阵 A 作用在 v 上，效果**等同于把 v 乘上一个数 λ**，只缩放，不转向。上面的例子里，`λ = 5` 对应 `v₁`，`λ = 2` 对应 `v₂`。

> [!WARNING] 三个容易搞错的地方
> - 特征向量是一个**方向**，不是唯一的一个向量：`(1,1)`、`(2,2)`、`(−3,−3)` 都满足 `Av = 5v`，算同一个特征向量，我们通常选最简单的或者把长度归一成 1。
> - 零向量不算特征向量（否则任何 λ 都“成立”，没有意义）。
> - λ 可以是**负数**（方向翻转）或 **0**（这个方向被压没了）。有些矩阵（比如旋转）根本没有实数特征向量，特征值是复数，本页只讲实数的情况。

## 二、手算：2×2 矩阵怎么求

### 1. 把 `Av = λv` 变成能解的方程

把右边移到左边：`Av − λv = 0`。注意 `λv` 可以写成 `λIv`（I 是单位矩阵，乘了等于没乘），所以：

```text
(A − λI) v = 0
```

这是一个“齐次线性方程组”（右边全是 0）。我们要的是**非零**解 v。回忆 [线性方程组、逆矩阵与秩](#/math/linear-systems)：如果矩阵 `A − λI` 可逆，这个方程只有 `v = 0` 一个解；所以要有非零解，`A − λI` 必须**不可逆**，也就是它的行列式为 0：

```text
det(A − λI) = 0         ← 特征方程
```

### 2. 先求 λ

```text
A − λI = | 4−λ    1  |
         |  2    3−λ |

det = (4−λ)(3−λ) − 1×2 = λ² − 7λ + 10 = (λ − 5)(λ − 2) = 0
所以  λ₁ = 5，  λ₂ = 2
```

> [!TIP] 2×2 的核对小技巧
> 2×2 的特征方程总是 `λ² − (迹)λ + det = 0`。**迹** trace = 对角线之和 = 4 + 3 = 7，行列式 `det = 4×3 − 1×2 = 10`。所以特征值之和 = 迹（5 + 2 = 7 ✓），特征值之积 = 行列式（5 × 2 = 10 ✓）。算完先对一下，错了马上知道。

### 3. 再求每个 λ 对应的 v

**λ = 5**：`A − 5I = [[−1, 1], [2, −2]]`，解 `(A − 5I) v = 0`：

```text
−x + y = 0
2x − 2y = 0        ← 和上一行是同一个方程（乘了 −2）
```

两个方程其实只有一个：`y = x`。这正是行列式为 0 的后果：方程“重复”了，所以有**一整条直线**的解。取 x = 1 得 `v₁ = (1, 1)`。

**λ = 2**：`A − 2I = [[2, 1], [2, 1]]`，方程 `2x + y = 0`，即 `y = −2x`，取 x = 1 得 `v₂ = (1, −2)`。

### 4. 用 Python 核对

```python
import numpy as np

A = np.array([[4, 1], [2, 3]])
vals, vecs = np.linalg.eig(A)
print(vals)             # [5. 2.]
print(vecs.round(3))    # 每一列是一个特征向量（单位长度）
# [[ 0.707 -0.447]
#  [ 0.707  0.894]]
for lam, v in zip(vals, vecs.T):
    print(np.allclose(A @ v, lam * v))   # True  True
print(np.trace(A), np.linalg.det(A).round(6))   # 7  10.0
```

第一列 `(0.707, 0.707)` 就是 `(1,1)` 除以它的长度 `√2`；第二列 `(−0.447, 0.894)` 是 `(1,−2)/√5` 的相反数，**正负号是任意的**，numpy 选哪个都对。

## 三、对角化与矩阵的幂

### 1. 换一副“眼镜”

既然 `v₁`、`v₂` 是两个不会被拧歪的方向，不如拿它们当新的坐标轴。任何向量都可以写成 `x = a·v₁ + b·v₂`，于是

```text
A x = a·(A v₁) + b·(A v₂) = 5a·v₁ + 2b·v₂
```

也就是说：**在 v₁、v₂ 这套坐标里，矩阵 A 只是“第一个坐标 ×5，第二个坐标 ×2”**，一个再简单不过的对角矩阵。写成矩阵乘法：

```text
A = P D P⁻¹

P = [v₁ v₂] = | 1   1 |    D = | 5  0 |    P⁻¹ = (1/3) | 2   1 |
              | 1  −2 |        | 0  2 |                | 1  −1 |
```

读法（从右往左）：`P⁻¹` 把普通坐标翻译成“v 坐标”，`D` 在 v 坐标里各自伸缩，`P` 再翻译回来。`P` 的列就是特征向量，`D` 的对角线就是特征值。

### 2. 为什么对角化让“幂”变简单

连乘两次：`A² = P D P⁻¹ · P D P⁻¹ = P D² P⁻¹`（中间的 `P⁻¹P` 抵消成 I）。同理 `Aⁿ = P Dⁿ P⁻¹`，而对角矩阵的 n 次方只要把每个对角元素各自 n 次方。

```text
A² = P · | 25  0 | · P⁻¹ = | 18   7 |       直接算 A·A 也是 [[18, 7], [14, 11]] ✓
         |  0  4 |         | 14  11 |
```

### 3. 手算：x = (3, 0) 被反复乘 A

先把 x 拆进两个特征方向：`x = a·(1,1) + b·(1,−2)`，即 `a + b = 3`、`a − 2b = 0`，得 `b = 1`，`a = 2`：`x = 2·v₁ + 1·v₂`。每乘一次 A，v₁ 的部分乘 5，v₂ 的部分乘 2：

```text
Aⁿ x = 2·5ⁿ·(1, 1) + 2ⁿ·(1, −2)

n=1：(10, 10) + (2, −4)   = (12, 6)      直接 A·(3,0) = (12, 6) ✓
n=2：(50, 50) + (4, −8)   = (54, 42)     直接 A·(12,6) = (54, 42) ✓
n=10：(19531250, 19531250) + (1024, −2048) = (19532274, 19529202)     两个坐标几乎相等，方向已经贴上 (1, 1)
```

这就是**幂迭代**的原理：反复乘 A，**特征值最大的方向（主特征向量）会越来越占主导**。PageRank、很多“求最大特征值”的算法都用它（第七节）。

### 4. 和 RNN 的梯度爆炸 / 消失

循环网络每一步都把隐藏状态乘一次同一个权重矩阵 W。先忽略激活函数和输入，`n` 步以后就是 `hₙ = Wⁿ h₀`。由上面的分析，每个特征方向各自被乘上 `λⁿ`，长期行为由**绝对值最大的特征值**决定，它叫**谱半径** `ρ(W)`（ρ 念“rho”）：

| 谱半径 ρ | 50 步 ρ⁵⁰ | 100 步 ρ¹⁰⁰ | 结果 |
| --- | --- | --- | --- |
| 0.9 | 0.0052 | 0.000027 | 信号衰减到几乎为 0：**消失** |
| 1.0 | 1 | 1 | 刚好保持 |
| 1.1 | 117.4 | 13781 | 信号被放大成千上万倍：**爆炸** |

反向传播时，梯度要沿时间一路乘回去，乘的是一连串雅可比矩阵（见 [链式法则与反向传播](#/math/chain-backprop)），同样的道理：`ρ < 1` 梯度消失，`ρ > 1` 梯度爆炸。

> [!WARNING] 这是“简化模型”
> 真实的 RNN 里有激活函数（`tanh` 的导数 ≤ 1，会让消失更常见）和每步输入，数字不会这么整齐。但“反复乘同一个矩阵，由最大特征值说了算”这个骨架是对的。常见对策：**梯度裁剪**（防爆炸）、**LSTM / 残差连接 / 归一化**（防消失）、让权重矩阵的谱半径初始化在 1 附近（如正交初始化），见 [RNN 与 LSTM：会“记事”的网络](#/aimodel/rnn)、[训练神经网络：优化器、正则化与常见坑](#/aimodel/training)。

## 四、对称矩阵：最乖的一类

**对称矩阵**：沿对角线镜像相等，`Sᵀ = S`，例如 `S = [[5, 2], [2, 2]]`。它有三条非常好的性质：

1. **特征值全是实数**（不会冒出复数）；
2. **不同特征值对应的特征向量互相垂直**；
3. 因此可以**谱分解**：`S = QΛQᵀ`，Q 的列是互相垂直的单位特征向量，Λ（大写 lambda）是特征值组成的对角矩阵。

手算验证：

```text
det(S − λI) = (5−λ)(2−λ) − 2×2 = λ² − 7λ + 6 = (λ − 6)(λ − 1)     → λ = 6, 1

λ = 6：S − 6I = [[−1, 2], [2, −4]]  →  −x + 2y = 0  →  v₁ = (2, 1)
λ = 1：S − 1I = [[ 4, 2], [2,  1]]  →  2x + y = 0   →  v₂ = (1, −2)

v₁·v₂ = 2×1 + 1×(−2) = 0        ← 垂直 ✓
```

把它们除以长度 √5，得到 `u₁ = (2,1)/√5`，`u₂ = (1,−2)/√5`，Q 的两列。因为 Q 的列互相垂直、长度为 1，**`Q⁻¹ = Qᵀ`**：对角化里“求逆”变成了“转置”，又便宜又稳。再把 `QΛQᵀ` 展开成“一片一片”的和：

```text
S = 6·u₁u₁ᵀ + 1·u₂u₂ᵀ

u₁u₁ᵀ = (1/5)·| 4  2 |     u₂u₂ᵀ = (1/5)·|  1  −2 |
              | 2  1 |                    | −2   4 |

6·u₁u₁ᵀ + u₂u₂ᵀ = (1/5)·| 24+1   12−2 | = (1/5)·| 25  10 | = | 5  2 |  ✓
                          | 12−2    6+4 |         | 10  10 |   | 2  2 |
```

每一片 `u uᵀ` 是“向 u 方向投影”的矩阵（见 [正交与投影：最小二乘与线性回归](#/math/projection)），所以**对称矩阵 = 各个正交方向上的投影，各自乘上特征值再加起来**。这个“拆成薄片”的想法，下一页 [奇异值分解（SVD）与低秩](#/math/svd) 会推广到任意矩阵。

AI 里常见的对称矩阵：**协方差矩阵** `XᵀX`、**Hessian**（二阶偏导矩阵）、**Gram 矩阵**（两两点积表）、**图拉普拉斯矩阵**、核矩阵。

> [!WARNING] 别把“好性质”用到一般矩阵上
> §二 的 `A = [[4,1],[2,3]]` 不对称，它的两个特征向量 `(1,1)` 和 `(1,−2)` 点积是 `1−2 = −1 ≠ 0`，**不垂直**。注意力里的 `QKᵀ` 一般也不对称。正交性、实特征值是“对称”这个条件换来的，不是特征向量天生就有的。

## 五、正定矩阵与“椭圆”

### 1. 二次型 `xᵀSx`

对 `S = [[5,2],[2,2]]` 和向量 `x = (x, y)`，`xᵀSx` 是一个**数**，展开是：

```text
xᵀSx = 5x² + 4xy + 2y²         例：x = (1, 1) 时 = 5 + 4 + 2 = 11
```

这是一个“碗”形的二次函数。它的等值线 `xᵀSx = 1` 是什么形状？换到特征坐标：令 `x = a·u₁ + b·u₂`，因为 u₁、u₂ 垂直，`xᵀSx = 6a² + 1b²`。所以 `6a² + b² = 1`，是一个标准椭圆，**半轴长 = 1/√λ**：沿 `u₁` 是 `1/√6 ≈ 0.41`，沿 `u₂` 是 `1/√1 = 1`。

### 2. 正定、半正定、不定

| 特征值 | 曲面形状 | 叫法 | 例子 |
| --- | --- | --- | --- |
| 全 > 0 | 碗，有唯一最低点，等值线是椭圆 | **正定** | 上面的 S（6, 1） |
| ≥ 0，有 0 | 山谷：某个方向完全平，等值线是一条条平行线 | 半正定 | 任何 `XᵀX`（因为 `xᵀXᵀXx = ‖Xx‖² ≥ 0`） |
| 有正有负 | 马鞍：一边上坡一边下坡 | 不定 | `[[1,0],[0,−1]]`，`x² − y² = 1` 是双曲线 |

### 3. AI 里的两个“椭圆”

**① 协方差矩阵**：数据云的形状（下一节），它是半正定的，特征值是各方向的方差。

**② 损失函数的 Hessian**：损失在某个点附近近似是一个碗 `½ θᵀHθ`（见 [泰勒展开与二阶信息](#/math/taylor)），H 是 Hessian，对称；它的特征值就是各个方向的“陡度”，等值线就是椭圆。陡峭程度悬殊，梯度下降就难走。手算一次（取 `H = S`，学习率 `η = 0.1`）：

```text
L = ½ xᵀSx，梯度 ∇L = Sx，更新  x ← x − η·Sx = (I − ηS)x
在特征坐标里每个方向各走各的：每一步，坐标乘 (1 − ηλ)
  陡方向 λ = 6：乘 1 − 0.6 = 0.4        平方向 λ = 1：乘 1 − 0.1 = 0.9
从 x = (1, 1) 出发，在 (v₂, v₁) 两个方向上的坐标是 (−0.447, 1.342)；
走 10 步后：(−0.447×0.9¹⁰, 1.342×0.4¹⁰) = (−0.156, 0.0001)
```

陡方向早就收敛了，平方向才走了约 65%。若把 η 调大到 0.4，陡方向的系数是 `1 − 0.4×6 = −1.4`，绝对值 > 1，直接**发散**。所以稳定的条件是 `η < 2/λmax = 1/3`；**条件数 `λmax/λmin`（这里是 6）越大，越难走**。这和 §三 的 RNN 是同一个机制：反复乘同一个矩阵。更完整的讨论见 [极值与优化：从梯度下降到 Adam，再到约束优化](#/math/optimization)。

## 六、协方差矩阵与 PCA：完整手算一次

**问题**：5 个样本，每个有 2 个特征 `(x₁, x₂)`，想压成 1 个数，尽量少丢信息。

```text
p₁ = (10, 20)   p₂ = (10, 21)   p₃ = (12, 20)   p₄ = (13, 21)   p₅ = (15, 23)
```

**第 1 步：去均值**。均值 `(12, 21)`，每个点减去它：

```text
p₁ → (−2, −1)   p₂ → (−2, 0)   p₃ → (0, −1)   p₄ → (1, 0)   p₅ → (3, 2)
```

**第 2 步：协方差矩阵** `C = XcᵀXc / (n−1)`（Xc 是去均值后的数据矩阵，每行一个样本，n = 5）。对角线是各特征的**方差**，非对角线是**协方差**（两个特征是否一起变大变小）：

```text
Σ x₁² = 4+4+0+1+9 = 18       Σ x₂² = 1+0+1+0+4 = 6       Σ x₁x₂ = 2+0+0+0+6 = 8
C = (1/4)·| 18  8 | = | 4.5  2   |         ← 对称矩阵，两个特征正相关（协方差 2 > 0）
          |  8  6 |   | 2    1.5 |
```

**第 3 步：特征值和特征向量**：

```text
det(C − λI) = (4.5−λ)(1.5−λ) − 4 = λ² − 6λ + 2.75 = 0
λ = (6 ± √(36 − 11)) / 2 = (6 ± 5)/2 = 5.5  或  0.5

λ = 5.5：−1·x + 2y = 0 → y = x/2 → PC1 = (2, 1)/√5 ≈ (0.894, 0.447)
λ = 0.5：   4x + 2y = 0 → y = −2x → PC2 = (−1, 2)/√5（取 x = −1；(1, −2) 方向也一样）
```

核对：`5.5 + 0.5 = 6 = 迹（4.5+1.5）` ✓。**总方差 = 迹 = 6**，PC1 占 `5.5/6 ≈ 91.7%`。

**第 4 步：投影**（点积）。得分 `zᵢ = pᵢ · PC1`：

```text
z₁ = (−2×2 + (−1)×1)/√5 = −5/√5 = −2.236     z₂ = −4/√5 = −1.789     z₃ = −1/√5 = −0.447
z₄ = 2/√5 = 0.894                           z₅ = 8/√5 = 3.578
```

两个检查：① 得分的方差 `(5 + 3.2 + 0.2 + 0.8 + 12.8)/4 = 22/4 = 5.5`，**恰好等于特征值 λ₁**，这就是“特征值 = 该方向上的方差”的含义；② 把 5 个数还原回二维（`zᵢ·PC1`），与原来的点差的平方和 = `2` = `(n−1)·λ₂ = 4 × 0.5`，**丢掉的信息量就是被舍弃的特征值**。

```python
import numpy as np

X = np.array([[10, 20], [10, 21], [12, 20], [13, 21], [15, 23]], dtype=float)
Xc = X - X.mean(axis=0)                  # 1. 去均值
C = Xc.T @ Xc / (len(X) - 1)             # 2. 协方差矩阵（等同于 np.cov(X.T)）
vals, vecs = np.linalg.eigh(C)           # 3. 对称矩阵用 eigh（特征值从小到大）
vals, vecs = vals[::-1], vecs[:, ::-1]   #    翻成从大到小
vecs[:, 0] *= np.sign(vecs[0, 0])        #    特征向量正负号是任意的，这里固定成第一个分量为正
print(C)                                 # [[4.5 2. ] [2.  1.5]]
print(vals, (vals / vals.sum()).round(4))   # [5.5 0.5] [0.9167 0.0833]
print(vecs[:, 0].round(4))               # [0.8944 0.4472]
z = Xc @ vecs[:, 0]                      # 4. 投影得分
print(z.round(3), z.var(ddof=1).round(3))   # [-2.236 -1.789 -0.447  0.894  3.578] 5.5
X1 = np.outer(z, vecs[:, 0])             # 只用 PC1 还原回二维
print(((Xc - X1) ** 2).sum().round(3))   # 2.0 = (n-1)·λ₂
```

> [!WARNING] PCA 的几个坑
> - **一定要先去均值**，否则“最分散的方向”会被均值的位置带偏。
> - **量纲不同要先标准化**：特征一个以“厘米”、一个以“千克”计，数值大的特征方差大，会霸占 PC1。常见做法是每个特征减均值、除以标准差。
> - 特征向量的**正负号是任意的**，不同库给出相反方向很正常。
> - PCA 只看方差，**不看标签**：“方差大”不等于“对任务有用”。

## 七、更多“谱”的应用（认识）

### 1. 马尔可夫链的稳态

天气：晴天明天仍晴 0.9、变雨 0.1；雨天明天转晴 0.5、仍雨 0.5。用向量 `x = (晴概率, 雨概率)`，转移矩阵（每一列和为 1）：

```text
P = | 0.9  0.5 |        明天的分布 = P · 今天的分布
    | 0.1  0.5 |

从雨天 (0, 1) 出发：(0.5, 0.5) → (0.7, 0.3) → (0.78, 0.22) → (0.812, 0.188) → (0.8248, 0.1752) → …
```

最终会停在一个**稳态** π，满足 `Pπ = π`，即 **λ = 1 的特征向量**：`(0.9−1)x + 0.5y = 0 → y = x/5`，归一化成概率 `π = (5/6, 1/6) ≈ (0.833, 0.167)`。另一个特征值是 `迹 − 1 = 1.4 − 1 = 0.4`，所以离稳态的误差每步乘 0.4，**收敛多快由第二大特征值决定**。

### 2. PageRank

网页的重要度 = 一个“随机上网的人”长期停留在这个页面的概率 = 链接转移矩阵（加上阻尼）的 λ = 1 特征向量，用 §三 的幂迭代求。3 个页面，页 0 链向页 1、2，页 1 链向页 2，页 2 链向页 0，阻尼 0.85，算出重要度 `(0.388, 0.215, 0.397)`：被“重要页面”指着的页 2 排第一。

### 3. 谱聚类

把数据看成图，拉普拉斯矩阵 `L = D − W`（W 是邻接矩阵，D 是对角的“度”矩阵）是对称半正定的。它**第二小的特征值对应的特征向量，正负号通常能把图切成两块**。例：两个三角形 {0,1,2}、{3,4,5} 用一条边（2–3）相连，`np.linalg.eigh` 给出第二个特征向量 `(−0.465, −0.465, −0.261, 0.261, 0.465, 0.465)`，符号一刀切开两个三角形。

## 八、动手：`eigh`、谱分解与幂迭代

```python
import numpy as np

S = np.array([[5., 2.], [2., 2.]])
vals, Q = np.linalg.eigh(S)                      # 对称矩阵专用：特征值升序、更快更稳
print(vals)                                      # [1. 6.]
print(np.allclose(Q.T @ Q, np.eye(2)))           # True：Q 的列互相垂直、长度为 1
print(np.allclose(Q @ np.diag(vals) @ Q.T, S))   # True：S = Q Λ Qᵀ

# 幂迭代：反复乘 A，方向会靠向主特征向量
A = np.array([[4., 1.], [2., 3.]])
x = np.array([3., 0.])
for _ in range(30):
    x = A @ x
    x = x / np.linalg.norm(x)                    # 每步归一化，防止数值爆掉
print(x.round(4), (x @ A @ x).round(4))          # [0.7071 0.7071] 5.0   方向→(1,1)/√2，xᵀAx→最大特征值 5
```

选择：**对称矩阵用 `eigh`**（结果是实数、特征向量正交）；一般方阵才用 `eig`（可能返回复数）；任意形状的矩阵用 `svd`（下一页）。

> [!QUESTION] 手算 `A = [[1, 2], [2, 1]]` 的特征值和特征向量。
> `det(A − λI) = (1−λ)² − 4 = λ² − 2λ − 3 = (λ−3)(λ+1)`，所以 `λ = 3` 或 `−1`（核对：和 = 2 = 迹，积 = −3 = det）。`λ = 3`：`−2x + 2y = 0`，`v = (1, 1)`；`λ = −1`：`2x + 2y = 0`，`v = (1, −1)`。两个向量点积为 0，因为 A 是对称矩阵。负特征值表示沿 `(1,−1)` 方向被**翻转**并保持长度。

> [!QUESTION] 某个循环网络的权重矩阵谱半径是 0.95。忽略激活函数，信号走 200 步大约剩多少？如果是 1.05 呢？
> `0.95²⁰⁰ ≈ 3.5×10⁻⁵`（几乎消失），`1.05²⁰⁰ ≈ 17293`（放大一万多倍）。哪怕只差 5%，长序列上也会差出天壤之别，所以谱半径要尽量靠近 1。

> [!QUESTION] PCA 里的 PC1 和 PC2 一定互相垂直吗？为什么？
> 一定。主成分是协方差矩阵的特征向量，而协方差矩阵是对称矩阵，对称矩阵不同特征值的特征向量互相垂直。（特征值相等时可以选成垂直的。）

> [!QUESTION] 二次函数 `f(x, y) = 2x² − y²` 的等值线 `f = 1` 是椭圆吗？矩阵是什么，特征值是多少？
> 矩阵 `[[2, 0], [0, −1]]`，特征值 `2` 和 `−1`，一正一负，是**不定**矩阵，曲面是马鞍，`2x² − y² = 1` 是双曲线，不是椭圆。只有特征值全为正（正定）时才是椭圆。

> [!QUESTION] 一个 4 维数据的协方差矩阵特征值是 `5, 3, 1, 1`。前两个主成分保留了多少方差？
> 总方差 = 特征值之和 = 10，前两个 `(5 + 3)/10 = 80%`。

> [!QUESTION] 一个损失函数在最优点附近的 Hessian 特征值是 `10` 和 `1`，梯度下降学习率最大能取多少才不发散？条件数是多少？
> 每个方向每步乘 `|1 − ηλ|`，要都小于 1：`η < 2/λmax = 2/10 = 0.2`。条件数 `10/1 = 10`。η 受最陡方向限制，而最平的方向收敛系数 `1 − η×1` 只能是接近 1 的数，因此走得慢——这就是条件数大的坏处。
