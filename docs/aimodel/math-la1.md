# 线性代数 1：向量与矩阵

> [!ABSTRACT] 一句话版本
> - **向量**：一列有序的数。既可以当成“一个对象的特征”（年龄、身高、收入），也可以当成空间里的“一支箭头”。
> - **点积**：两个向量“对得有多齐”。越相似，点积越大；这就是 AI 里**相似度**的来源。
> - **矩阵**：一张数字表格，也是一台“**变换机**”：丢进去一个向量，吐出来另一个向量（旋转、拉伸、压扁……）。
> - **矩阵乘法**：一次性做很多个点积。神经网络里每一层本质上就是 **`输出 = 矩阵 × 输入 + 偏置`**。
> - 学会这一页，你就能看懂神经网络里 90% 的“公式长什么样”。

## 为什么 AI 需要线性代数

想象你要让计算机判断一张照片里有没有猫。计算机看到的不是“猫”，而是**一大堆数字**（每个像素的亮度）。要处理一大堆数字，我们需要一套**整齐、高效的语言**——这就是线性代数。

| 现实里的东西 | 线性代数里叫什么 | 例子 |
| --- | --- | --- |
| 一个人的信息 | **向量** | `(年龄=25, 身高=175, 月薪=12000)` |
| 一张灰度图 | **矩阵** | 28×28 个像素亮度 |
| 一批图片 | **张量**（更高维的“表格”） | 100 张 28×28 的图 |
| 神经网络的一层 | **矩阵乘法** | `y = W x + b` |
| 一个词的“含义” | **向量**（词嵌入） | `[0.12, -0.5, 0.8, …]` 共几百~几千个数 |

> [!NOTE] 线性代数的“线性”是什么意思
> 简单说：**先放大再相加 = 先相加再放大**。线性的变换性质非常好，计算机算起来极快（GPU 最擅长的就是矩阵乘法）。神经网络用“线性变换 + 一点点非线性”搭出各种复杂能力。

## 一、向量：一列数，也是一支箭头

### 1. 两种看法

**看法一（数据视角）**：向量就是一行/一列数字。

```text
小明 = (25, 175, 12000)       小红 = (30, 165, 15000)
```

**看法二（几何视角）**：二维向量 `(3, 2)` 就是从原点出发，**向右 3 格、向上 2 格**的一支箭头。三维向量就是三维空间里的箭头；几百维的向量我们画不出来，但**规则完全一样**。

### 2. 向量能做的两件基本事

| 运算 | 规则 | 例子 | 直觉 |
| --- | --- | --- | --- |
| **加法** | 对应位置相加 | `(1,2) + (3,1) = (4,3)` | 先走一段，再走一段 |
| **数乘** | 每个数都乘同一个数 | `3 × (1,2) = (3,6)` | 把箭头拉长 3 倍 |

> [!TIP] 在 AI 里的样子
> 经典的“词向量”例子：**国王 − 男人 + 女人 ≈ 女王**。词被变成向量后，“含义”的关系就变成了向量的加减。

### 3. 向量的“长度”

二维向量 `(a, b)` 的长度就是勾股定理：`√(a² + b²)`。

```text
|(3, 4)| = √(9 + 16) = 5
```

n 维向量一样：把每个数平方、相加、再开方。

## 二、点积：衡量“有多像”

### 1. 怎么算

对应位置**相乘，再全部加起来**：

```text
a = (1, 2)，b = (2, 1)
a · b = 1×2 + 2×1 = 4
```

再看一个对比：

```text
a = (1, 2)，c = (2, -1)
a · c = 1×2 + 2×(-1) = 0      ← 点积为 0，说明两支箭头互相垂直（完全“不相关”）
```

### 2. 几何含义

```text
a · b = |a| × |b| × cos θ
```

所以 **cos θ = (a · b) ÷ (|a|·|b|)**，叫做**余弦相似度**：

| cos θ | 含义 |
| --- | --- |
| 接近 **1** | 方向几乎相同，非常相似 |
| 接近 **0** | 互相垂直，没有关系 |
| 接近 **-1** | 方向相反，含义相反 |

我们的例子里 `cos θ = 4 ÷ (√5·√5) = 0.8`，说明 a 和 b **比较相似**。

### 3. 点积在 AI 里无处不在

- **搜索/推荐/RAG**：把问题和文档都变成向量，**点积（或余弦）越大，越相关**；
- **神经元**：一个神经元就是“输入向量与一组权重向量做点积，再加个偏置”；
- **注意力机制**：Transformer 里“这个词该关注哪个词”，就是用点积算出来的，见 [注意力与 Transformer：大模型的骨架](#/aimodel/transformer)。

## 三、矩阵：一张表格，一台变换机

### 1. 是什么

矩阵就是**数字排成的长方形表格**。`m × n` 的矩阵有 m 行、n 列。

```text
A = | 1  2 |      ← 2 行 2 列的矩阵（记作 2×2）
    | 3  4 |
```

### 2. 矩阵 × 向量：批量点积

所以**一层神经网络就是一个这样的“批量点积”**：

```text
输出 = W · 输入 + b        （W 是权重矩阵，b 是偏置向量）
```

输入有 784 个数、输出想要 128 个数，那么 W 就是一个 128×784 的矩阵：**128 个神经元，每个神经元一行权重，各自和输入做点积**。

### 3. 矩阵乘矩阵

两个矩阵相乘 `A × B`：**A 的每一行，和 B 的每一列，做点积**。

```text
| 1 2 |   | 0 1 |     | 1×0+2×1   1×1+2×0 |     | 2  1 |
| 3 4 | × | 1 0 |  =  | 3×0+4×1   3×1+4×0 |  =  | 4  3 |
```

你会发现结果是把 A 的两列**调换了位置**（因为 B 是“交换两列”的矩阵）。

**必须记住的两条规则**：

1. **形状要对得上**：`(m × n) × (n × p) = (m × p)`。中间的 n 必须相等，结果取两头的 m 和 p。
2. **一般不满足交换律**：`A × B ≠ B × A`。**顺序很重要**（先旋转再平移 ≠ 先平移再旋转）。

```text
(2 × 3) × (3 × 4) = (2 × 4)   ✓
(2 × 3) × (2 × 4) = ？         ✗  中间不匹配，不能乘
```

> [!TIP] 形状检查是写神经网络代码的第一技能
> 绝大多数“报错”都是形状对不上。养成习惯：**每一步都写出形状**，如 `(批大小, 784) × (784, 128) = (批大小, 128)`。

常见的变换矩阵：

| 想要的效果 | 矩阵（二维） |
| --- | --- |
| 放大 2 倍 | `[[2,0],[0,2]]` |
| 只在 x 方向拉伸 3 倍 | `[[3,0],[0,1]]` |
| 逆时针旋转 θ | `[[cosθ, −sinθ],[sinθ, cosθ]]` |
| 水平翻转 | `[[−1,0],[0,1]]` |
| 什么都不做（单位矩阵 I） | `[[1,0],[0,1]]` |

**连续做两次变换 = 把两个矩阵乘起来**。这就是为什么“多层神经网络 = 许多矩阵相乘”。

> [!WARNING] 只有线性变换的网络太“笨”
> 无论叠多少层线性变换，合起来**还是一个线性变换**（一个矩阵就能代替）。所以神经网络必须在每层之间加一个**非线性**的“激活函数”，才能学会复杂的东西，见 [MLP：神经元、多层感知机与反向传播](#/aimodel/mlp)。

## 五、几个常用的概念（认识即可）

| 概念 | 一句话 | 例子 |
| --- | --- | --- |
| **转置** `Aᵀ` | 行列互换 | `[[1,2],[3,4]]ᵀ = [[1,3],[2,4]]` |
| **单位矩阵 I** | 乘了等于没乘 | 对角线是 1，其余 0 |
| **逆矩阵 A⁻¹** | 把变换“撤销” | `A × A⁻¹ = I`；不是所有矩阵都有逆 |
| **行列式 det** | 变换把面积放大了几倍（带正负号） | `det [[1,2],[3,4]] = 1×4 − 2×3 = −2` |
| **线性方程组** | `A x = b`，求 x | `x = A⁻¹ b`（A 可逆时） |
| **秩 rank** | 矩阵里“真正独立的信息有几层” | 秩低 → 信息有冗余（可压缩） |

关于行列式：`det = 0` 表示变换把平面**压扁成一条线**（信息丢了，不可逆）。

## 六、动手：用 NumPy 验证

```python
import numpy as np

a = np.array([1, 2]); b = np.array([2, 1])
print(a @ b)                                   # 点积 → 4
cos = a @ b / (np.linalg.norm(a) * np.linalg.norm(b))
print(cos)                                     # 余弦相似度 → 0.8

A = np.array([[1, 2], [3, 4]]); x = np.array([5, 6])
print(A @ x)                                   # 矩阵×向量 → [17 39]

B = np.array([[0, 1], [1, 0]])
print(A @ B)                                   # [[2 1] [4 3]]  （交换列）
print(B @ A)                                   # [[3 4] [1 2]]  （交换行）→ 和 A@B 不一样！
print(np.linalg.det(A))                        # -2.0
```

| 线性代数 | 神经网络里 |

## 自测：你真的懂了吗？

> [!QUESTION] 向量 (3, 4) 的长度是多少？它和 (4, −3) 的点积是多少，说明什么？
> 长度 = √(9+16) = 5。点积 = 3×4 + 4×(−3) = 0，说明两个向量**互相垂直**，在方向上完全“无关”。

> [!QUESTION] 一个 (5 × 3) 的矩阵能和 (3 × 7) 的矩阵相乘吗？结果的形状是什么？
> 可以，因为中间的 3 对得上。结果是 **5 × 7**。记忆法：中间的数消掉，剩两头。

> [!QUESTION] 为什么说“神经网络的一层就是一次矩阵乘法”？
> 一层有很多神经元，每个神经元都对输入做“加权求和（点积）”。把所有神经元的权重按行堆起来就是矩阵 W，对输入 x 做 `W·x`，就是同时完成了所有神经元的点积，再加上偏置 b 即可。

> [!QUESTION] 先做变换 A 再做变换 B，和先做 B 再做 A 结果一样吗？
> 一般不一样。矩阵乘法不满足交换律。比如“先旋转 90° 再沿 x 方向拉伸”和“先拉伸再旋转”得到的图形不同。
