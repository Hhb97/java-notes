# 概率与信息论入门：损失函数从哪来

> [!ABSTRACT] 一句话版本
> - 模型的输出往往不是“答案”，而是**各个答案的概率**（“这是猫的概率 90%”）。
> - **softmax** 把一堆任意数字变成加起来为 1 的概率；
> - **最大似然**：好的模型应该让“真实发生的事情”概率尽量大；
> - 把“让概率最大”换个说法，就是**让交叉熵（−log 概率）最小**——这就是分类和大语言模型的**损失函数**；
> - **困惑度**是交叉熵的指数形式，用来衡量语言模型“有多困惑”。

> [!NOTE] 你只需要掌握“直觉 + 会算几个小例子”
> 概率统计很大，本页只挑**理解 AI 必需的部分**，其余都可以日后再补。

## 一、概率：衡量“有多可能”

概率是 **0 到 1** 之间的数：0 = 绝对不会发生，1 = 一定发生。

| 例子 | 概率 |
| --- | --- |
| 抛一枚均匀硬币得到正面 | 0.5 |
| 掷一枚骰子得到 6 | 1/6 ≈ 0.167 |
| 明天下雨 | 比如 0.3 |

**规则**：所有互斥结果的概率**加起来等于 1**。（硬币：0.5 + 0.5 = 1。）

### 联合、条件与独立

| 概念 | 含义 | 例子 |
| --- | --- | --- |
| 联合概率 P(A, B) | A 和 B **同时**发生 | 又是男生、又喜欢足球 |
| 条件概率 P(A \| B) | **已知 B 发生了**，A 发生的概率 | 已知是男生，他喜欢足球的概率 |
| 独立 | 知道 B 对 A 毫无影响 | 两次抛硬币互不影响 |

**公式**：`P(A | B) = P(A, B) ÷ P(B)`；独立时 `P(A, B) = P(A) × P(B)`。

> [!TIP] 大语言模型本质就是条件概率
> 语言模型做的事：**给定前文，预测下一个词的概率**，即 `P(下一个词 | 前面所有词)`。

## 二、贝叶斯：用证据更新信念

### 经典例子：疾病检测

某病在人群中的患病率是 **1%**。检测方法：真有病时 **99%** 检出阳性；没病时有 **5%** 的误报（假阳性）。

你检测出**阳性**，真的有病的概率是多少？直觉常常说“99%”，其实：

```text
假设 10000 人：
  有病：100 人 → 阳性 99 人
  没病：9900 人 → 阳性 9900×5% = 495 人
阳性共 99 + 495 = 594 人，其中真正有病的只有 99 人：
  P(有病 | 阳性) = 99 ÷ 594 ≈ 16.7%
```

**贝叶斯公式**（只是把上面的思路写成公式）：

```text
P(A | B) = P(B | A) × P(A) ÷ P(B)
  后验      似然       先验     证据
```

**含义：先有个“先验”信念，看到证据后，更新成“后验”信念。** 垃圾邮件分类（朴素贝叶斯）、很多概率模型都基于它。

## 三、期望与方差：平均值和波动

| 概念 | 含义 | 例子 |
| --- | --- | --- |
| **期望 E[X]** | **加权平均**：每个结果 × 它的概率，再相加 | 掷骰子的期望 = (1+2+…+6)/6 = 3.5 |
| **方差 Var(X)** | **偏离平均有多远**（离散程度），偏离的平方的期望 | 方差大 → 数据很散 |
| **标准差** | 方差开根号，和数据同单位 | |

```text
例：赌博 A：50% 赢 100、50% 输 0    期望 50，方差大
    赌博 B：必得 50                  期望 50，方差 0
```

机器学习里：**损失函数就是对所有样本“误差”的期望（平均）**；PCA 找“方差最大”的方向（见 [线性代数 2：特征值、SVD 与 PCA](#/aimodel/math-la2)）。

在 AI 里：参数的**随机初始化**常用正态分布；数据**标准化**（减均值、除标准差）就是把数据变成均值 0、标准差 1；很多模型把“噪声”假设成正态分布，这时**最小化均方误差**就等价于最大似然（下文）。

## 五、最大似然：让“已经发生的事”概率最大

### 例子：判断硬币是否公平

抛一枚不知道是否公平的硬币 10 次，得到 **7 次正面、3 次反面**。设“正面概率”为 p，哪个 p 最合理？

**似然** = 在这个 p 下，**恰好观察到这组结果**的概率：

```text
L(p) = p⁷ × (1−p)³
```

| p | L(p) |
| --- | --- |
| 0.3 | 0.3⁷×0.7³ ≈ 0.000075 |
| 0.5 | 0.5¹⁰ ≈ 0.00098 |
| **0.7** | 0.7⁷×0.3³ ≈ **0.00222** |
| 0.9 | 0.9⁷×0.1³ ≈ 0.00048 |

**p = 0.7 时，观测到的数据最“可能”**——这就是**最大似然估计**：选使数据概率最大的参数。结果和直觉一致：7/10 = 0.7。

> [!TIP] 机器学习训练 = 最大似然
> 训练分类模型，就是调整参数，使“**训练集里每个样本的真实标签出现的概率**”乘起来最大。概率连乘不方便（数字极小），所以取 **log**（连乘变连加），再加个负号变成“最小化”——于是得到**交叉熵损失**。

## 六、softmax：把任意分数变成概率

神经网络最后一层常输出一组**任意实数**（叫 logits，比如 `(2, 1, 0)`），要把它们变成**概率**：

```text
softmax(zᵢ) = e^zᵢ ÷ Σ e^zⱼ
```

```text
z = (2, 1, 0)
e^2 = 7.389，e^1 = 2.718，e^0 = 1       求和 = 11.107
概率 = (7.389/11.107,  2.718/11.107,  1/11.107) = (0.665, 0.245, 0.090)     ← 加起来 = 1
```

**温度（temperature）**：把分数除以一个 T 再 softmax。T 越小，分布越“尖”（几乎全押最大的）；T 越大越“平”（更随机）。大模型生成文字时的“temperature”参数就是它。

## 七、交叉熵：分类和语言模型的损失

### 直觉

模型给出了概率。**真实答案的那一类，模型给的概率越高越好**。我们用 **−log(真实类别的概率)** 来衡量“错得多离谱”：

| 模型给“真实类别”的概率 | −ln(概率) | 意味着 |
| --- | --- | --- |
| 0.99 | 0.01 | 几乎完全正确，损失很小 |
| 0.665 | **0.408** | 还行 |
| 0.245 | 1.41 | 不太对 |
| 0.01 | 4.6 | 非常错，损失很大 |

上面猫/狗/鸟的例子里，若真实答案是**猫**，损失 = −ln(0.665) = **0.408**；若真实是**鸟**，损失 = −ln(0.090) = **2.41**（更大）。

```text
交叉熵损失（单个样本）：L = − log P(真实类别)
整个数据集：             对所有样本取平均
```

**为什么用 −log 而不用别的**：

- 概率越小惩罚越大，且**对“自信地答错”惩罚极重**（0.01 → 4.6）；
- 与最大似然完全等价（上一节）；
- 与 softmax 搭配时，**梯度形式非常简洁**：`预测概率 − 真实标签（独热向量）`，训练稳定。

### 语言模型的损失

大语言模型每个位置都在做“**下一个词的分类**”（类别数 = 词表大小，几万到十几万）。**训练损失 = 对每个位置求交叉熵，再取平均**。

### 困惑度（Perplexity）

```text
困惑度 = e^(平均交叉熵)
```

- 平均交叉熵 = 2.3 → 困惑度 ≈ 10：可以理解为“模型每次预测下一个词时，**平均像是在 10 个等可能的候选里犹豫**”；
- **越低越好**。完美模型困惑度为 1。

## 八、信息熵与 KL 散度（认识即可）

| 概念 | 一句话 | 公式 |
| --- | --- | --- |
| **熵 H(p)** | 一个分布的“**不确定性**”：越均匀越高 | `H = −Σ p·log p` |
| **交叉熵 H(p,q)** | 用“q 的编码方案”去编码“真实分布 p”的平均代价 | `−Σ p·log q` |
| **KL 散度** | q 与 p 的**差距**（不是对称的“距离”） | `KL(p‖q) = H(p,q) − H(p)` |

- 训练分类模型时，真实分布 p 是**独热**的（正确答案概率 1，其余 0），熵为 0，所以**最小化交叉熵 = 最小化 KL 散度**；
- KL 散度在 **VAE、知识蒸馏、强化学习（PPO/RLHF 里约束模型别偏离太多）** 里都会出现。

## 九、动手

```python
import numpy as np

z = np.array([2.0, 1.0, 0.0])
p = np.exp(z) / np.exp(z).sum()
print(p)                                # [0.665 0.245 0.090]

true = 0                                # 真实类别：第 0 类（猫）
loss = -np.log(p[true])
print(loss)                             # 0.408

# 带温度的 softmax
def softmax(z, T=1.0):
    e = np.exp(z / T); return e / e.sum()
print(softmax(z, 0.5))                  # 更尖
print(softmax(z, 2.0))                  # 更平

# 困惑度
losses = np.array([2.1, 2.5, 2.3])     # 每个位置的交叉熵
print(np.exp(losses.mean()))            # ≈ 10
```

## 自测：你真的懂了吗？

> [!QUESTION] 为什么阳性检测结果为阳性，真患病的概率只有约 17%？
> 因为患病率很低（1%），没病的人数远多于有病的人，即使误报率只有 5%，误报的绝对人数（495）也远大于真阳性人数（99）。要看“基数”，这就是贝叶斯公式里先验的作用。

> [!QUESTION] softmax 的作用是什么？温度怎么影响结果？
> 把任意实数分数变成和为 1 的概率分布，分数越大概率越大。温度越小分布越尖锐（几乎只选最大的），温度越大分布越平均、输出更随机。

> [!QUESTION] 交叉熵损失为什么是 −log(真实类别的概率)？
> 它与最大似然等价：训练就是让真实标签的概率尽量大；取 log 把连乘变连加，加负号变成最小化。概率越小损失越大，自信地答错惩罚极重，而且与 softmax 配合时梯度形式简洁稳定。

> [!QUESTION] 困惑度是什么？数值越低代表什么？
> 困惑度是平均交叉熵的指数，可理解为模型预测下一个词时平均在多少个等可能候选之间犹豫。越低说明模型对真实文本预测得越准。

> [!QUESTION] 最大似然估计在抛硬币例子里给出什么结果？
> 观察到 10 次中 7 次正面，使这组数据出现概率最大的 p 是 0.7，也就是用频率估计概率。
